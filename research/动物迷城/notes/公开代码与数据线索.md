# 《动物迷城》公开代码、数据与工具线索

核查日期：2026-10-10。用途：说明研究可以深入到哪一层证据，供后续机制设计参考。此次仅检索公开网页、GitHub 目录与文本文件；没有安装游戏、下载/执行第三方工具、读取用户存档或对游戏做逆向。

**阶段说明：**本页保留第一阶段的发现与读取范围。同日后续已下载固定版本的文本源码至临时缓存，并深入追踪 Provider、桥接、事件和队列；没有执行社区程序。新增结论、实读范围及动态资料站核验见[第 05 篇](../05-社区源码深读与Z实现参考.md)，本页的“本轮未读”只指第一阶段，不覆盖后续进展。

## 1. 结论与证据边界

**本轮未发现 Metal Head Games 官方发布的完整游戏源码。** 已发现的是社区资料站、旧 Demo 数据文档、社区 Mod 源码及官方修改器 DLC。公开检索未发现，不等于已经证明不存在；也没有官方“永不开放源码”的声明可据此引用。

目前可继续到三层：

| 证据层 | 已找到什么 | 能支持的研究 | 不能直接证明什么 |
|---|---|---|---|
| 官方产品/功能说明 | Steam 官方 Game Modifier Toolkit DLC | 官方支持哪些状态/难度修改、修改后的成就限制 | 原作内部源码、存档格式、所有计算公式 |
| 社区内容数据 | 现行 Vercel 资料站；2022 Demo Markdown 仓库 | 字段、条件、物品/技能/任务关系的核对线索 | 内容在当前版本一定可达、未使用数据已实装、数据表就是运行逻辑 |
| 社区程序代码 | ModLoader、FastDialog、Discord 状态 Mod | 插件自身的实现，观察者如何读取或封装游戏状态；可借鉴的数据模型 | 原作完整架构、所有状态更新规则、插件对当前版本实测有效 |

下一轮最有价值的是把“某动作的前置条件 → 代价 → 效果 → 解锁关系”整理成小型证据表，用官方说明、资料站、可复核的游玩记录交叉检查。单独抄数据数值、或看到一个 C# 类型就推断原游戏架构，都容易越过证据。

## 4. C08. 官方 Game Modifier Toolkit 的准确定位

[Steam 官方 DLC 页面](https://store.steampowered.com/app/3700610/)，开发者 Metal Head Games、发行商 Spiral Up Games，商店显示发行于 2025-07-17，为需要本体的免费 DLC。

官方列出的能力包括恢复日常资源、调整战斗伤害、增加检定基础点数、降低行动耗时、忽略属性限制。启用后会禁用该存档成就；可通过新建或读取启用前存档恢复正常成就条件。

它可以在将来拥有合法可运行版本时帮助开展有控制的机制观察，但使用它的实验必须记录修改项，不能据此描述原始难度。**该 DLC 是官方修改功能，不是源码、Mod SDK 或数据导出器。** 本轮没有安装。

## 5. 推荐的后续读取顺序

1. **优先现行资料站的单条数据交叉核验**：从项目当前需要的机制选 10—20 个条目，记录页面、核查日期、明确游戏版本（若页面提供）、前置/代价/效果/依赖，保留“无法确定可达”的标记。
2. **选读 ModLoader 的实际桥接与事件调用处**：当前只确认了社区 API 表层。若要讨论角色状态、关系、时间与任务的连接，下一步需追到 Provider 的赋值及调用处；仍应表述为社区桥接所观察到的实现，不能升级成官方源码结论。
3. **用可重复游玩验证关键边界**：例如同一物品在行动/战斗的不同代价，某任务接受/完成是否发生跨日事件，关系阈值是否只改变 UI 还是实质开放权限。代码线索与可观察行为一致后，才提高结论可信度。
4. **创作采用抽象关系与自有实现**：本项目可以参考动作模型、条件系统、任务状态与数据驱动配置的组织方式。上述社区内容及原作文本/美术不自动成为可复制的项目资产，也不自动变成已批准需求。

本文件新增的线索没有改写研究主稿里的正式版机制数值。发现更强证据后，应逐条更新来源和版本边界，而不是用一份旧 Demo 数据全量替换现有结论。
