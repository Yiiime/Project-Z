# 《动物迷城》机制证据笔记

调研日期：2026-10-10。用途：供未来原创 Demo 的系统拆解、设计复盘与实机验证使用。本笔记基于公开文献检索，**没有安装、试玩或逐帧观看完整流程，不是实测报告**。包含逃脱路线与任务结构剧透。

证据等级：A＝开发者/发行商的一手公开资料；B＝明确标版本的玩家攻略或社区资料；C＝早期攻略、媒体观察或版本不明资料。下文“分析”是对事实的设计解读，不表示开发者曾这样解释设计意图。

## 1. 最值得保留的机制判断

《动物迷城》的可借鉴核心是：**玩家在有期限、分时开放且受监管的封闭场所里，将有限行动机会转换成人际关系、能力、工具、权限和环境变化，最后把这些准备拼成逃脱方案。** 这是一种高密度、手工编排的系统型叙事 RPG，不宜误记为随机生成的无限监狱生活模拟。

两个容易拆错的地方：

- “交朋友”同时影响人物故事、交易物品、技能来源和任务条件，不能只复刻成好感数值。
- “打工”同时连接收入、表现分、进入某区域的正当理由，以及短暂离岗时的调查机会，不能只复刻成赚钱小游戏。

上述为跨来源分析，证据见 M01—M05、M12、M16—M18。

## 2. 时间与空间规则

### 已确认事实

- 官方以托马斯入狱后剩余 **21 日**描述剧情压力。[M02]
- 日程将上午劳动、午餐、下午放风、晚餐/晚间活动、锁门分开。不同时间使不同设施、人物、活动可用。[M06]
- 2023 年攻略明确：移动位置和送礼不推进全局时间；听信息、工作、偷窃、制作、如厕、洗浴等行动消耗时间。正式版玩家评论也描述“执行行动才走时钟”。因此不能把普通探索理解为一直流逝的实时计时。[M07、M20]
- 某些机会另有局部行动窗口，例如医生离开后的短暂自由活动，做一次调查就扣除窗口时间。[M12]
- 官方 2026 年的更新另有降低超时风险的模式机制；“所有模式 21 天之后都必须失败”已经不是安全结论，详见版本校验表。

### 日程时间存在冲突，不能拼成一张伪精确表

| 来源 | 来源列出的时间 | 本笔记处理 |
|---|---|---|
| 社区 Wiki《Boulderton Prison》 | 07:45 点名、08:00 工作、12:00 午餐、13:00 放风、17:30 晚餐、21:30 锁门 | 页面没有明确游戏构建号，只记录为该来源口径 |
| Neoseeker，标明 EA 1.3.81.8-RC | 08:00 点名、22:00 锁门 | 旧版本，不直接移植到当前版 |
| 2023-11-08 游侠攻略 | 工作 08:30—12:00 | EA 历史口径 |
| 2026 官方第四篇 | 医生 17:30 下班 | 明确一手时间事实，可单独采用 |

设计分析：时间压力至少有三层——全局剩余天数、每天可访问的时段、某次潜入的局部窗口。它们分别约束长期取舍、行程规划和即时决策。制作 Demo 时要明确三种时钟怎样互相结算，不能一个全局倒计时包办全部。

## 3. 资源并非一条“体力条”

| 层 | 已核实作用 | 对玩家选择的影响 |
|---|---|---|
| 精力 Stamina | 工作、训练、搜索等行动会消耗；休息、睡眠、物品恢复 | 限制一天能做多少事情 |
| 专注 Focus | 用于挑战失败后的重投，随时间或物品恢复 | 为不确定行动保留余地 |
| 健康 Body | 低于 30 进入虚弱，力量、敏捷约减半 | 身体差会进一步降低行动成功率 |
| 心态 Mind | 低于 30 会影响智力、魅力；失败与噩梦可令其下降 | 失败可能产生跨系统后遗症 |
| 饱腹 Satiety | 随时间下降；长期饥饿继续消耗健康和心态 | 用餐是维持行动条件的一环 |
| 金钱 | 电话、商品、改善伙食、帮派设施等支出 | 决定能否把时间压力转成经济支出 |
| 表现分 | 用于申请工作、囚室修缮 | 正式管理体系中的权限资源 |
| 声望 | 可由拳赛、理发店任务提高，开放人物和内容 | 非正式社会地位，与表现分不同 |

基础资源见 M02；表现分和声望见 M04。不要混淆战斗中的 Health/Energy 与日常的 Body/Stamina：社区战斗资料明确，战斗受伤会反馈到日常健康，因此“打赢”也可能付出生活成本。[M09]

分析：需要保留的是资源间的耦合，而非照抄所有数值。一个可检验的链条是：**为了赶进度挤压休息/饮食 → 身心状态下降 → 检定能力下降 → 失败、额外恢复或重试 → 又失去行动时间。** 这是可能出现的负反馈，不应在自制 Demo 中默认无限放大；必须测试低资源玩家是否仍有可理解的恢复出口。

## 4. 四属性、专长和技能是三种东西

官方明确四属性为力量、敏捷、智力、魅力。装备、技能与临时食物/药品效果会影响属性。每种属性有 10 个专长，以对应属性经验激活，后续激活成本提高；发现技能与启用技能分开，启用需要对应的技能点，技能点也由属性经验取得。[M04]

这意味着经验的用途、知识的获得和当前构筑不是同一个按钮：

1. 先通过某种生活、阅读、娱乐、人物关系或事件发现能力。
2. 再决定把有限成长资源用在哪里。
3. 在当前目标下启用有用的能力组合。

社区技能表提供了三个小而有代表性的跨系统例子：修理技能可恢复工具耐久；“程序设计入门”一类阅读能力开放电子密码破解；海獭相关能力连接临时钥匙/开锁工具。技能不仅给战斗百分比，也开放新的环境操作方式。[M10]

分析：NPC 和书籍可以成为“可探索的技能树节点”。玩家先对某个人/某本书产生兴趣，随后才发现它能解决环境问题。可借鉴的因果关系是“能力来源有叙事载体”，不必复刻原人物、书名和技能命名。

## 5. 检定：两枚骰子，而非 d20

官方规则是：**目标点数＝行动难度－基础点数；两枚骰子的总和达到目标则成功。** 基础点数受相关属性、技能与道具影响；一般失败后可花 1 点专注重投一次。[M02]

旧版具体攻略将其写为 2D6，并列双六必成功、双一大失败等特殊结果；也记载累计进度型行动。由于祝福、技能、模式、后续更新可以改变特殊结果或补救，不能把这一组基础规则当成全部例外都适用的完整公式。[M08、M10]

以通常的公平 2D6 为假设，**纯数学说明**：达到 7 的概率是 21/36≈58.3%，达到 6 是 26/36≈72.2%，达到 5 是 30/36≈83.3%。这不是本次实测数据，也未加入特殊成功/失败与重投修正。它说明在阈值中部增加 1 点能力会明显改变成功率，“凑道具和状态”可能比反复赌骰更有价值。

分析：检定最好拆成两类来理解。一次性判定决定门是否打开；累计判定决定完成同一工程需多少时间、精力和耐久。它们带来不同的失败体验，Demo 如果全部做成单次随机失败，就会丢掉原作的准备与工程感。

## 6. 社会关系、交易与帮派

官方规则：交谈/礼物提高好感；更深入关系会增加可交易品类，甚至可以买到对方装备中的物品，了解过去。三个帮派为大脚、尖牙、黑爪；入帮需要 100 帮派信任，可由帮派任务获得。加入后获得本帮设施、活动与半价商店等优惠，但会失去其他帮派任务/商店及结识其老大的机会，对其成员的说服更难。[M03]

个人关系与帮派信任因此必须分开建模。官方 2025-07-29 更新还明确修正过：须先“结识”囚犯才能“深入了解”。这证明它包含状态门槛，不能只用一个达到阈值的数值代替全过程。[M14]

玩家礼物攻略还记录了**各人物不同的 bonding objective**，并注明托马斯与鲍勃版本存在道具差异。适合参考“共同经历/特定要求 → 开放深入关系”的形式，不宜抄一张旧版送礼数值表当完整社交设计。[M15]

分析：帮派是有机会成本的中期承诺。加入让某一套经营/成长更便宜，却收窄跨阵营选择，形成与“先广泛调查再选边”不同的节奏。仅做三个商店而无排他性，无法复现原作的政治与生存取舍。

## 7. 战斗、工具、违规与隐蔽行动

社区战斗资料描述回合制战斗，管理战斗生命和能量，含徒手、武器、休息、招式和使用物品。武器/招式存在命中、暴击、流血、眩晕、护盾等交互；战斗失去的生命会影响战后身体状态。[M09]

物品表显示工具可同时具有材料、武器、挖掘/拆卸等类别，例如锤子既可挖掘又可作钝器；不同拆卸工具提供不同操作加成。部分物品消耗耐久，并可由修理能力延长可用性。[M11、M10]

潜入/偷窃要区分至少三种情况：

- 与人物直接交互时的偷窃或勒索，由相应能力和检定开放。[M03]
- 获得短暂无人看管窗口后，执行调查、搜索、改造。[M12]
- 路线上遭遇守卫/探照灯时的敏捷检定及被发现后后续危险。[M13、M17]

**未确认完整算法**：本次资料不足以还原所有摄像头视野、搜身判定、违禁值阈值、被抓后的全部物品损失规则。不要从某个攻略截图推导出统一实时潜行 AI。官方能确认禁闭会限制活动并损伤身心状态。[M05]

分析：一件物品有多种可用语义，才使“我能不能把这个当工具”成为有效推理。实现时可以用物品标签加场景条件，而不是每个物品写全局万能脚本；但每条可行解必须有可发现的提示，避免靠攻略才知道隐藏配方。

## 8. 逃脱路线：研究结构，避免把指南当当前穷尽列表

以下是托马斯路线的**已被社区指南记录的代表性方案**，名称对应成就；不承诺涵盖所有正式版版本、模式和结局。[M13、M16]

| 路线 | 机制焦点 |
|---|---|
| The Star：屋顶滑翔 | 工作权限、白天勘察与改造、夜间通路、知识/材料准备 |
| The Moon：洗衣房管道 | 隐藏空间、挖掘/除锈、夜间潜入、末段体能与战斗 |
| The Tower：医院信号塔 | 医疗场所访问、通路改造、攀爬和探照灯风险 |
| The Chariot：暴动机会 | 帮派任务前置、特定日期、冲突选择 |
| Strength：拳赛外出 | 连胜与声望带来的特殊许可，比赛之外的逃脱机会 |
| The Sun：探视相关 | 调查证据、人物关系、谈判形成协助 |
| The Magician：特殊事件 | 传闻线索、时间与道具条件驱动的隐藏解法 |

路线并非互相隔离的七张关卡；牢房后的通道、下水道等准备会被多条方案复用。不同路线的最后门槛分别偏向制作、体能、关系、事件时机或战斗。若只照抄出口动画，会失去大部分玩法。

鲍勃正式版攻略（自注 V2.0.0.33-RC）列出洗衣房、理发店地下水路、医院、屋顶等方案，并把救出芬妮/准备专用工具加入主线。他与托马斯不能视为仅换头像：同一设施的可行条件、主线触发、同伴约束会改变。一个清楚的多解例子是药房门禁：准备药品/相应技能可在诊疗窗口行动；也可以记住卡号，等待外部复制；有破解能力又可缩短等待。[M17]

分析：复用空间而改变角色能力、任务依赖和护送对象，比从头再造同体量地图更适合作为第二角色方案；但首个 Demo 应先验证单主角的闭环。

## 9. 失败、读档与版本边界

| 项目 | 证据与限制 |
|---|---|
| 小失败 | 判定失败可失去心态、资源或窗口；一般可消耗专注补救，个别模式可有额外手段。[M02、M08] |
| 战斗代价 | 胜负之外，受伤会带入日常健康。[M09] |
| 被惩罚 | 禁闭损失可行动时间，并损伤身心。[M05] |
| 路线失败 | 如信号塔被探照灯发现后，面临枪击与进一步判定；不能当成每次失败都只减一个数。[M13] |
| 读档 | 旧版新伊甸/中心区可用“记忆回溯”，贫民窟限制该功能。不能从这里推断 2026 全模式存档矩阵。[M08] |
| 2026 调整 | 官方“冠军版本”公告确认：托马斯新伊甸、鲍勃白道新增土拨鼠徽章，携带它在第 21 天睡眠后仍停留在第 21 天；也新增冠军模式。只适用于公告指定条件，不写成全难度无限模式。[M19] |

建议未来实机优先核对：当前构建号；全模式与读档能力；全局钟/小游戏钟；耗时是否在选择前完整显示；行动跨越饭点/锁门如何处理；低资源恢复路径；失败能否阻断唯一主线；路线共享准备究竟保留哪些；New Game+保留技能、关系、知识和任务状态的区别。

## 10. 可借鉴的跨系统因果链（分析，不是新增原作事实）

| 因果链 | 为什么有效 | Demo 复现时必须保留的关系 |
|---|---|---|
| 劳动 → 钱/表现 → 更好工作 → 新区域 → 调查线索 | 生存行为和主线推进共用内容 | 工作不仅支付工资，还改变权限或信息可见性 |
| 礼物/经历 → 信任 → 买到随身物品/能力 → 改变环境 | 让角色价值出现在任务以外 | 人物奖励应对至少一种场景障碍产生作用 |
| 白天合法勘察 → 改造/留后门 → 夜间越界 → 新路径 | 同一空间在不同规则下重复利用 | 持久环境状态、时段规则和返回线路 |
| 属性/装备/状态 → 改善检定 → 少耗时间与精力 → 腾出其他安排 | 成长兼具能力与效率意义 | 不能只有战斗变强，其他行动也须可感知改善 |
| 入帮 → 降低一侧成本 → 关闭另侧机会 → 路线偏向 | 将福利做成有代价的承诺 | 加入前能理解收益和主要损失 |
| 窃取/暴力 → 快速获利 → 关系/监管后果 → 长期受限 | 产生角色扮演而非唯一最优解 | 后果有针对性，且存在另一种成本不同的解法 |
| 多条路线共享前置 → 中途发现新解 → 调整计划 | 保护前期投入，奖励探索知识 | 共享路径应足够有价值，又不能让所有结局完全同质 |
