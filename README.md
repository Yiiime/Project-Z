**当前设计基线：**[游戏设计总案 v2](docs/游戏设计总案-v2.md)（2026-10-11 更新）。采用 21 天倒计时、四章、三条基础终局路线与关键节点操控 Z。白天在《动物迷城》式俯视像素世界自由行动，夜间用手机观看白发 Z 的近景直播，发送弹幕、赠礼与自愿报名随机连麦。已取消精力机制；行动耗时间，交易/赠礼扣金币或库存，字段统一为 `gold` / `gold_delta`。普通行走、读字、打字、AI 等待不耗游戏时间，节目推进一次结算时段，不按弹幕条数扣时。当前只实现上述 D1 子集，完整故事、长期关系和数值平衡仍待后续制作与试玩。
