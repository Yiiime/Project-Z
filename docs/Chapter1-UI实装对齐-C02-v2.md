# Chapter1 UI 实装对齐 · C.02 v2

2026-10-12 · Godot 4.7.2 · 游戏版本 `0.2.0-d1-ui`

本轮优化的是 `game/` 中真实可玩的 D1 界面。参考已认可的[白天概念集 v3](../ui/chapter1-day-v3/index.html)及[C.02 横屏直播](../ui/live-phone-v2/index.html)。保留当前像素世界、角色移动与原有一日规则；旧白天地图插画不替换当前像素地图。

## 概念如何进入实际界面

| 界面 | 实装变化 | 对应概念 |
| --- | --- | --- |
| 探索 HUD | 上下渐变承托信息；左上日期、地点、时钟与下一日程；右上金币、细线图标与快捷键；左下两级目标 | `01-explore.jpg` 的轻 HUD 与信息层级 |
| NPC 对话 | 底部横向对话框，半身像独立透明层；姓名、身份、正文、编号选项分级；支持鼠标与 1—9 选择，禁用选项说明原因 | `08-dialogue.jpg` |
| 咖啡馆与商店 | 右侧工作/小店切换，选中商品与实际库存；费用、完成时间和购买按钮固定在底部，商品说明可滚动 | `05-cafe-shop.jpg` |
| 行动预览 | 开始时间 → 结束时间；耗时、金币变化、完成后余额分别呈现；开始/确认与取消区分 | 行动确认概念与现有规则预览 |
| 背包 | 物品/记录/许可三类可操作分页；只列实际持有物品；选中物品的图、数量、来源时间和用途；独立空背包状态 | `09-backpack.jpg` |
| 工作与日程 | 三步工作进度；订单重点文字；日程按真实预览与完成标记展示状态，长内容可滚动 | 白天工作、机会窗口概念 |
| 直播 | 月牙 + Z/LIVE 标识、轻量文字记录、玩家消息细线强调、底部输入及礼物/连麦入口；左侧底部抽屉与节目确认，保留 Z 近景与房间背景 | `01-watching-zh.jpg` |
| 标题、日记与日终 | 共用留白、细线、蓝黑面板、字体与浅蓝主操作；日记和结果仍读取本局真实记录 | 昼夜共用视觉语言 |

共享样式集中在 [ui_kit.gd](../game/scripts/ui_kit.gd)：蓝黑 `#101c2b`、正文 `#f2f3f5`、次级文字 `#b5c1d0`、主操作 `#c5d9ec`，使用 Noto Sans SC 与 Manrope。25 个 SVG 细线图标来自现有概念页的图标定义，采用 128 像素导入尺寸，减少在大图标处放大的模糊。

白天组件在 [day_ui.gd](../game/scripts/day_ui.gd)，主界面与快捷键接线在 [main.gd](../game/scripts/main.gd)，夜间组件在 [night_view.gd](../game/scripts/night_view.gd)。UI 不直接授予金币、库存、权限或关系，动作仍经过原有核心预览与提交。

## 资产

新增许舟、林乔、陆岑三个对话半身像，分别生成、分别导入，沿用既有陈叔插画的表现方向；共用底部对齐，地图 NPC 精灵保持原样。每张为 1254×1254 RGBA PNG，已检查真实透明通道。参考与完整生成记录见 [portraits/prompts.json](../game/assets/ui/portraits/prompts.json)。该记录包含本地来源路径，已从 Web 运行包排除。`game/evidence/.gdignore` 将截图与日志排除出 Godot 资源导入，运行包仅含实际游戏资源。

Z 的四表情图集、礼物插画与夜间房间背景继续复用。这轮没有把半身像当成动画绑定；没有新做 Live2D、联网 AI、口型或语音。

## 机制依据与边界

沿用研究卡 K01（日程与机会窗口）、K03（资源与行动取舍）、K08（物品准备与多用途）的既有适配：行动前可见耗时与金币变化；背包里白天取得的物品与晚上赠送/展示相连；错过窗口不伪装成仍可执行。这里只调整呈现与可发现性，不改行动定义、数值、营业时间、随机抽选或存档结构，因此不新增机制采用决策。

无精力。走路、阅读和输入不扣时间；购买扣金币，送已购礼物扣库存；节目推进仍是独立确认。字体支持中英文混排不等于完整游戏已经国际化，当前文案仍以中文为主。
