# Chapter1 一天 Demo：开工与资产清单

2026-10-12。用户已认可白天 v3 与夜间 C.02，要求实现一个完整日的 Demo。当前已有可运行 Godot 工程与 D1 自动化证据；本文件记录从开工到本轮交付的范围和资产状态，不取代完整 D1—D3 方案。

## 工程核查与本轮决定

开工前核查时，仓库没有 project.godot、场景、规则核心或游戏存档，只有 HTML/CSS 图册与直播交互设计预览。预览中的库存与节目状态只存在于页面局部变量，未当作世界状态复用。主机实际安装 Godot 4.7.2.stable.official.ed1daf0bf，并有同版 Web 单线程模板。

现已在 [game/](../game/README.md) 建立 Godot 4.7.2 + GDScript 工程，Compatibility 渲染；有 [project.godot](../game/project.godot)、[主场景](../game/main.tscn)、[规则核心](../game/core/day_state.gd)、[场景与界面脚本](../game/scripts/main.gd)以及自动化测试。复用视觉素材和设计规则，重新实现移动、规则、存档及真实引擎控件。浏览器由[启动试玩.command](../game/启动试玩.command)提供 [127.0.0.1:61327](http://127.0.0.1:61327/) 本地入口；[启动Godot.command](../game/启动Godot.command)运行原生试玩，编辑器可直接打开 project.godot。没有 Windows/iOS 包。

本轮从 D1 07:00/40 金币开始，到 D1 23:00复盘与保存结束。可移动探索、NPC 对话、报到、场务交接、咖啡工作、购买、制作、午晚间日程、手机直播、赠礼、文字连麦和日终总结。保留礼物/作品两种准备，允许错过机会或没有被记住的日终，不强行发出 D4 邀请。无精力，查看、行走和聊天不耗游戏分钟。作者离线回应读取本局事实，明确显示离线模式，不宣称已经接入真实模型、语音或 Live2D。

## 机制采用与适配

- K01：统一行动预览与提交，活动前显示耗时/结束时间；节目每段 40 分钟只由继续操作结算。
- K02：报到解锁公开场务，工作范围不等于灯塔或私人后台许可。
- K03：白天购买和制作形成真实库存，晚间礼物/投稿读取该库存；未准备不能伪造同等结果。
- K04：NPC 提供有来源的服务与知识；Z 只记住有依据的交流，不靠重复刷屏无限累加。接通连麦后最多 3 轮离线作者接话，依据真实场务、咖啡、制作或铃声事实，不新增认识、物品或许可；次数从已保存消息派生，读档不重置，结束后回普通弹幕。
- K08：时间换金币、金币换礼物或材料；上午工作与工作台窗口有机会成本。
- K11：场务失败保留问题，合法窗口复核后才发一次工资；中断活动通过 pending 恢复。
