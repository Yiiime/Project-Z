# 地图像素重制与空间交互 v1

2026-10-12 · **状态：白天像素地图已接入 D1，已完成本轮自动化回归、原生截图与局部浏览器连续走图。**验证范围见 §6；用户验收与原作动态参数标定尚未完成。

## 1. 本轮决定与边界

用户确认将白天地图从 C.02 延伸的精细整景画风改为更接近《动物迷城》的像素 RPG 场景，保留海岛、现有人类角色和 D1 地点分工。夜间 C.02 近景直播不在本轮范围。旧地图、角色图集与设定图保留，不覆盖原资产。

本轮重建地图的尺度、资产分层、移动与交互空间，接入现有 D1 主流程。时间、金币、库存、任务与直播规则沿用[一天 Demo](Chapter1-一天Demo-开工与资产清单.md)和[规则核心](../game/core/day_state.gd)，不增加 D2、地点功能或新任务。

“还原《动物迷城》”是本轮体验目标，不能写成已经测得其内部参数：本轮已实际查看官方展示截图；尚未对原作实机录屏测量移速、相机跟随、碰撞容差、交互距离或动画帧时长。下文尺寸是本项目候选，需要走图调校。

## 2. 参考依据与改造前问题

原作视觉依据：[官方场景图](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/1735700/a71a8e0f994a4941546e3b3e2fd05504fe076758/ss_a71a8e0f994a4941546e3b3e2fd05504fe076758.1920x1080.jpg)、[官方办公室图](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/1735700/7fd63c6bf72de5767723b93eafb6871067b0d555/ss_7fd63c6bf72de5767723b93eafb6871067b0d555.1920x1080.jpg)。可复核的既有观察见[美术与地图观察](../research/动物迷城/notes/美术与地图观察-2026-10-11.md)：固定斜俯视、有厚度的物体、环境与信息面板分工。截图不提供原始图块尺寸或完整交互规则。

本轮检查旧 `island-clean.png`、`cafe-clean.png`、`props-clean.png` 与人物图集，发现：

- 地板、建筑、家具、前景及部分 NPC 烘焙成一张底图，无法与主角共同排序；拆出轮廓还需补齐其后地面。
- 角色缩放基准室外 100、室内 250，而移动、碰撞与交互距离不随之统一，室内外相对身体尺度不同。
- 可走区、阻挡与热点分别手填；视觉上的门、栏杆和家具没有共同的空间定义。
- 整图纹理和高分辨率人物缩小后的像素密度不一致。再次给整图加“pixel art”提示词不能解决比例与行动问题。

因此改用统一格尺下的模块资产和场景装配；旧图保留气氛与地点辨识参考。

## 3. 统一格尺与资产生产

| 项目 | 当前实现 / 调校值 | 证据与边界 |
|---|---|---|
| 世界角色 | 裁切后缩放至约 40 世界像素高，脚底为定位点 | 主角四方向、每向四帧；室内外同尺度，生成原图并非原生 40px 画布 |
| 地面格尺 | 32 单位为尺度参考；地纹以 64/96 单位重复并降低细纹对比 | 纹理按可走多边形精确裁切，碰撞不强制格化；未修改生成 PNG |
| 世界视口 | 独立 640×360 `SubViewport`，启用像素定位 | 场景在低分辨率世界渲染；高清中文与 HUD 使用独立主 UI |
| 显示缩放 | 主 UI 为 1600×900；默认 1280×720 窗口使世界放大 2 倍 | 1600×900 预览为 2.5 倍 Nearest，仍有非整数倍率导致像素宽度不均的限制；非原作参数 |
| 移动与交互 | 当前移速 110 世界单位/秒；脚底 12×8；普通交互半径 42，陈叔 48 | 先满足可站立、距离、合法侧及无阻挡；这些是本项目调校值，未经原作实机标定 |
| 美术 | 固定斜俯视、统一光向、清晰像素簇 | 同一标尺下检查人、门、桌、墙；不依靠物件逐个任意拉伸修比例 |

素材分为五张 1254×1254 图集：[地形](../game/assets/pixel-v1/terrain.png)、[室外建筑/物件](../game/assets/pixel-v1/outdoor.png)、[室内家具/道具](../game/assets/pixel-v1/indoor.png)、[主角](../game/assets/pixel-v1/player.png)、[NPC](../game/assets/pixel-v1/npc.png)。原始生成图保留，裁切区域及脚底锚点记录在 [atlas-regions.json](../game/assets/pixel-v1/atlas-regions.json)。已逐张观察并接入实际场景；生成结果不服从严格等格，采用实测裁切，不能直接按提示词格数切图。

装配时分开三件事：

1. **美术层：**地面 → 与人物共同排序的物件 → 需要独立遮挡的前墙、树冠或屋顶。可交互 NPC 独立成对象。
2. **空间层：**以物件实际落地部分配置阻挡；角色以脚底检测，树冠、桌面等可遮人部分不等于整块禁止行走。
3. **状态层：**门、箱子、交互点读取现有规则事实。靠近只开放操作入口，不自动授予权限、物品或任务结果。

每个可交互对象至少明确：稳定 ID、脚底/地面锚点、占地轮廓、交互点或有效侧、可见状态。地图、美术与逻辑应能追溯到同一对象，避免隔墙触发与视觉入口错位。

本轮已补海岸外侧石护岸与水线、室内墙脚/窗分格/南侧出口、独立接触影和合法目标 E 键帽。接触影留在地面层，不随物件遮挡淡化；NPC 键帽按人物脚底放在头右侧，避免遮脸。餐桌图自带四椅，装配按组合处理；咖啡馆入口对准右侧门，陆岑位于工作台右侧可直接接近。M 地图读取相同的场景边界、物件、热点与玩家位置。

## 4. 先验证的街区与接口

以“码头小街 → 咖啡馆门口 → 室内柜台”为核心样板，复用原有 D1 空间，不新增任务。户外至少包含直路、转角、树或高物、栏杆与门；室内包含柜台和桌间过道。道具间继续承担真实搬箱与工作台交互。

世界重建继续提供现有主流程使用的地点、交互 ID、移动与活动状态接口；`main.gd` 已为新空间接入进行适配，核心经济、时间、任务规则未改。需要协调的接口变化须检查主场景与保存恢复，不能因画面更换让原有 D1 路径失效。

最小行为链：从码头走到门口 → 进咖啡馆 → 绕过桌子 → 在合法一侧接近柜台 → 返回户外 → 进入道具间搬箱。应能在正常镜头连续完成，不能只用测试定位到目标点代替走图。

K05 的原卡仍是多解及成本，不将其改名为权限系统；本轮空间合法性是现有方法可执行的前置保障。机制原文见[研究框架](../research/动物迷城/02-Demo借鉴与验证框架.md)，决策索引同步到[机制采用记录](机制采用记录.md)。
