共同方向：玩家远程观看手机直播，Z 为正面近景的白发虚拟主播；弹幕、礼物、报名连麦均在手机界面内。示例金钱为金币74，阿树的赠礼不改变玩家余额。三图已取消精力和旧岛券字样。手机电池/信号图标只属于设备外观，不是游戏行动资源。

本轮是静态美术候选，不具备真实弹幕发送、连麦、语音或 Live2D 动画。在线1,286及20:10为构图示例，不是联网或计时验证。用户选择后，再完成选定方案的礼物抽屉、报名/抽中/未中、连麦中、主播不同回应等状态。

[交互与规则说明](设计说明.md)为随包快照；维护源为项目 `docs/手机直播交互与美术方案-v1.md`。当前 D1—D3 首先支持已持有礼物发送；手机直购为后续候选，不在选美术时附带扩大经济系统。

使用内置 image_gen 生成/编辑，沿用 `ui/chapter1-pixel-v2/images/03-z-character.png` 的身份与旧 UI 的色材参照。[提示词](prompts.json)含三方案和 C 的文字修订；[manifest](manifest.json)与页面内嵌清单一致。迭代目录不进入交付包，旧图保留历史。

本轮参考 K01 的时间规则、K03 的昼夜准备联系、K04 的真实交流和 K08 的资源取舍；规则文档已取消精力、统一金币，单条消息不扣整段40分钟。真实交互与实际平衡仍待开发验证。
