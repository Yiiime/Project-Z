## 地图与文字规则

- 全岛外观图是缩远的构图概览；实际行走镜头应保持 04 码头这样的较近尺度。扩大不意味着把人物缩得更小来塞下整座岛。
- 原型先尝试约 3×2 个正常镜头范围。它是待验证布局目标，不能把这张图当作已经测量的碰撞地图或宣称面积扩大固定倍数。
- 使用两条环路组织咖啡馆、公共广场、居住区与工作建筑，海岸步道提供辨认与停留空间；具体可通行性、行走时间和回头路仍须灰盒验证。新增风景不自动追加任务和 NPC。
- M 图只负责查询，打开/关闭与普通行走不推进游戏时间，不默认传送。建筑外观、许可、内部探索状态分别记录。图内装饰人物不是实时追踪功能。
- 场景内部去重复地名和解释牌；HUD 保留简短地点，地图标地名，交互面板保留任务、代价和反馈。不是禁止所有世界内招牌。

## 视觉规则与生产边界

- 参考《动物迷城》的固定斜俯视、物体厚度、像素质感、低干扰 HUD 与像素场景/清晰文字分工。Z 按用户要求采用人类白发女性，与原作动物角色不同。
- 新 Z 的识别锚点为长银白发、月牙发饰、浅色开衫、冰蓝裙、深蓝腰带；平时表情克制，感兴趣或被回应时柔和。玩家仍使用原棕发、橙色外套形象，未重设计。
- 这些图用于统一外观、构图、界面和角色设定；生成图存在像素密度不完全统一的问题，不能直接缩小后充当最终精灵。
- 正式生产需要无 UI 的背景、独立建筑/家具/屋顶、透明人物图集、表情头像、UI 组件与可编辑源文件；被遮住的地面与背面需补绘。碰撞和导航另行制作。
- 角色板的四方向与动作属于参考姿势，不是已经对齐画布、脚底、帧时长的动画。直播画面也不是完成了实时表情绑定。

原作观察见项目 `research/动物迷城/notes/美术与地图观察-2026-10-11.md`。[官方商店展示](https://store.steampowered.com/app/1735700/Back_to_the_Dawn/)用于环境与 HUD；[社区地图攻略](https://game.3loumao.org/250408076)用于地图菜单形式，2025-01-11 发布、游戏版本未知。M 快捷键来自本项目用户要求，并非已核实原作按键。

9 张最终图使用内置 image_gen 生成/编辑；提示词保存为 [prompts.json](prompts.json)，清单与尺寸见 [manifest.json](manifest.json)。`iterations/` 只保存未采用版本，不进入交付包。一次简化地图尝试误置道具间标签，已舍弃；最终使用地点关系正确的插画缩略图。

本地图集验证范围是图像可读性、角色一致性、直播相邻状态和离线画廊。走动、遮挡、门禁、M 快捷键、任务、存档与真实 AI 仍待开发验证。
