# C.02 月光直播 · 横屏 PC 精修

2026-10-11。用户已选择 C 方向继续，并要求简洁、更好的弹幕与礼物排版以及国际化。本交付用于评审这次精修，尚非最终美术批准。

直接打开 [index.html](index.html)；无需构建、账号或网络请求。右上角切换中文 / EN，展开图标进入沉浸预览，Esc 关闭面板或退出沉浸。重置恢复演示数据。

这是本地 HTML/CSS 交互设定稿。Z、字幕、其他观众、时钟及礼物库存为示例数据；没有接入 AI、语音、真实观众、随机抽选、Live2D 或游戏存档。页面刷新即重置，不能当作 D1—D3 玩法验收。

## 设计选择

- **构图**：保留 C 的 16:9 横屏与角色近景，去掉实体手机厚边框。手机观看关系通过频道、LIVE、聊天室与互动操作表达；这仍是播放器画面。
- **层级**：Z 的脸与手处于右侧安全区。左下显示观众发言，右下是 Z 字幕；顶部只保留频道和简短状态。礼物和连麦面板替换左侧聊天室，不覆盖脸。
- **弹幕**：单列、真实字体，无逐条黑色卡片；昵称低一层级，正文保留对比，玩家发言用一条细竖线区分。没有彩虹用户名或每条头像。新消息进入记录；不会伪造任意输入得到 AI 回应。
- **礼物**：常态仅显示紧凑赠送记录；点击礼物展开一件已有“小礼物”的展示、库存与赠送操作。月牙吊牌、象牙纸与蓝色缎带对应 Z 的发饰、开衫和腰带，像素材质与场景统一。它是既有 small gift 的美术设定，不新增商品类型。
- **色彩**：午夜蓝底色、银白主文字、低饱和月蓝强调。暖色主要留在室内灯光和礼物细节。主按钮使用浅月蓝，不再用金边和发光描边营造质感。
- **字形**：Manrope 用于拉丁文字和数字，Noto Sans SC 用于中文；正文常规字重、标题中等字重，时间和余额采用等宽数字。完整字体本地随包，避免只裁固定文案导致自由输入缺字。
- **字号**：字体随直播画面而非整个浏览器宽度调整，且有最小字号；在 1280×720 的评审窗口中，直播画面约 1028×578，弹幕正文为 15px。全屏游玩可获得更大的画面和文字。当前验证目标是 PC，不以小手机纵屏作为验收目标。

## 可体验范围

| 操作 | 本地预览反馈 | 未实现边界 |
|---|---|---|
| 发送弹幕 | 文本进入消息记录，显示已发送；空白不可发；支持中文输入法 | 不调用模型，不增加识别/好感，不宣称已被 Z 读取 |
| 赠送小礼物 | 明确确认后库存 1→0，赠送记录与图标变化，金币仍为 74 | 不接真实商城、经济账本或幂等收据 |
| 随机连麦报名 | 报名→已报名；可取消；不会请求麦克风权限 | 不自动开奖、不执行真实通话 |
| 继续观看 | 明示 20:10→20:40 后确认，演示时间改变一次 | 时刻是艺术快照；不是引擎的 segment_advance 计时实现 |
| 中文 / English | 控件、说明、昵称示例、观众文案、字幕与无障碍名称切换 | 自己输入的消息保留原文；未验证全部语种、RTL 或全 Unicode |
| Esc / 键盘 | 关闭面板并返回入口，面板打开时隐藏聊天区不进焦点序列 | 不是完整手柄导航实现 |

沿用研究 K01 的日程与 K03 的白天准备进入夜间：本轮只改变视觉承载，保持免费输入、预购库存赠送、自愿报名、单独节目推进。没有精力条，也没有替代的行动点；货币为金币。本轮没有新增或重平衡游戏机制。
