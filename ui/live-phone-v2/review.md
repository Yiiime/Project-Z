# C.02 本地设计检查

日期：2026-10-11。以下仅证明本地 UI 预览，不是游戏系统、AI 或动态角色验收。

## 视觉自检与改进

| 维度 | 检查与改进 | 结果边界 |
|---|---|---|
| 排版 | 初版按画面比例缩放导致小窗口字太小；加入容器条件与字号下限。中文和英文逐态查看，保留内容换行。 | 1280×720、1440×900、1920×1080 评审窗口检查无横向溢出；1280 与1920英文礼物/连麦面板在舞台边界内。 |
| 视觉层级 | 去除厚手机边框、逐条消息黑底、重复 Z 标识和大金色按钮。角色脸部与手部安全区不被面板覆盖。 | 主界面、中英礼物和英文连麦截图已查看；未声称其他未画状态同样通过。 |
| 色彩 | 银白主文字、月蓝辅助，深色局部渐变承托弹幕，礼物暖色只作细节。 | 静态背景可读性已目视检查；未来动态背景仍需独立对比度测试。 |
| 交互 | 实际输入消息、送出库存礼物、报名与取消、节目确认、语言切换。修复赠礼后残留星星瓶图标，以及隐藏聊天按钮可聚焦的问题。 | 本地 DOM 中礼物变成小礼物图标、库存归零、金币74、互动时间20:10；明确推进后20:40且按钮停用；隐藏聊天区有 inert。 |
| 一致性与原创性 | 礼物由矢量临时图替换成独立像素资产；月牙、银白与蓝色缎带呼应 Z。UI采用克制的现代字体，与角色像素图像分层。 | 风格是本项目 C 方向的精修；不是第三方现成 UI 素材，也不以“一流”作为未经验证的质量认证。 |

## 实际验证

- 浏览器 UI 操作：中文输入可发送，新消息保留；礼物发送减库存、余额不动，重复发送按钮禁用；报名可以取消；普通互动不改示例时钟；明确确认节目推进只演示一次。
- 中英切换覆盖当前观看、礼物与报名控件和说明；自输入内容不随切换被翻译或重写。当前两字体共约17.11 MiB，官方文件完整性及文案字形覆盖检查见 `fonts/sources.md`。
- 页面控制台最终查询没有 error / warn。
- `node --check app.js` 通过。未新增镜像实现的单元测试。
- 导出以实际浏览器渲染为准。检查发现初次英文观看截图落在聊天渐入过渡中，已在稳定状态重新导出；五张最终导出均为1600×900 JPEG。

没有完成真实 AI/Live2D、随机抽选概率、游戏存档、引擎计时和经济状态验收；没有进行全部语言、全部窗口尺寸、完整屏幕阅读器或手柄测试。
