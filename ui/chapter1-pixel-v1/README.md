## 本轮理解

第一章先解决四件事：一张连接地点的可活动岛图；能置入场景的人形玩家；有明确工作、问询、交易与门禁反馈的白天地点；能输入弹幕并看见 Z 点名、表情及动作回应的夜间直播界面。当前阶段交付美术方向和界面状态，不制作游戏运行工程。

视觉依据为《动物迷城》的常规探索截图：近正交斜俯视、横竖排列的地面、切顶室内、暗轮廓像素人物、旧木材与金属细节、角落 HUD 和深色硬边交互面板。人形玩家和 Z 沿用本项目身份与服装。具体像素源图尺寸、相机参数及 UI 组件实现尚未定为原作规格。

## 开发采用口径

- 相机：场景以固定斜俯视、横竖地面主轴组织；屋顶与前墙在室内去除。地图总览采用更小比例。
- 角色：玩家为棕发、锈橙外套、深色裤装、工作牌与斜挎包；Z 为黑色短发、米白外套、蓝色裙装。路人与 Z 区分发型和主色。
- HUD：左上为日期／七段数字时钟／下一时间窗；左下为精力和岛券；右下顺序为头像→地图→背包。不同图片的轻微边框和尺寸差异在引擎里由同一组件消除。
- 场景交互：右侧面板在确认前显示行动、时间和精力代价、收入或许可状态。基础通路、操作人物和门口不能被面板遮住。
- 直播：程序状态拥有时间、库存与是否可发送；AI 表达被约束在已提交的行动结果中。20:00 输入与 20:40 回应属于同一个开场段，消息只结算一次。
- 不按图中咖啡黑板的装饰价格新增商品；只实现当前 D1—D3 规格中的岛券交易。角色板上的简介也不是额外剧情条件。
- 图中人物板供重绘和动画设计参考，不能直接当作透明底、统一网格的最终图集。环境也须拆分地面、建筑、道具、遮挡、碰撞和灯光。

本轮仅把现有机制可视化：K01 的时间成本、K02 的工作收益与许可、K03 的公开节目线索、K04 的被认出反馈。未修改章节门槛、任务规则与人物知识状态。

## 审查与修正

已逐图检查构图、中文主操作、角色辨识、行动成本与画面连续性。已修正咖啡馆/地图路人与 Z 过度相似、人物侧面朝向不明确、地图与背包图标次序不一致、部分时钟样式不一致。保留初版在 iterations/，不作为当前交付图。

两张夜间图复核：房间和家具布局连续；20:00→20:40、精力100→98、岛券74不变、礼物×1不变；回应用同一弹幕与话题，没有提前私聊或邀约。08 的第二行对白接近面板下边缘但仍完整；实现时使用可伸高或逐句显示的正文组件，保留足够内边距。

图形当前用于确定方向。真实像素网格、动画帧、走路/碰撞、门禁判断、文字排版伸缩及 AI 连续对话尚未通过游戏运行验证。
