# 来自月亮的 Z · Chapter1 一天 Demo

2026-10-12 · UI v2（0.2.0-d1-ui）。Godot 4.7.2 Web 构建，游玩范围为第一天 07:00—23:00。

## 启动

macOS：解压完整文件夹，双击 `启动试玩.command`。脚本使用本机 Python 3 启动本地服务并打开浏览器，不上传文件。保留终端窗口；结束试玩后可按 Ctrl+C 关闭服务。

其他已安装 Python 3 的桌面环境：在此文件夹执行 `python3 serve_demo.py`；Windows 也可使用 `py serve_demo.py`。请勿直接双击 `build/index.html`，游戏需要通过本地 HTTP 服务加载。

这是浏览器试玩包，不是 Windows/macOS 安装器。建议使用桌面横向窗口。存档保存在当前浏览器的此本地地址下，清理网站数据或更换浏览器不会自动迁移存档。

## 操作

- WASD / 方向键移动，靠近目标按 E。
- M 地图，I 背包，J 日记，T 日程，Esc 菜单。
- 鼠标或数字键 1—9 选择对话，鼠标操作活动；行动确认时显示时间及金币代价。
- F5 / F9 手动保存 / 读取，也可使用菜单，避免浏览器快捷键冲突。
- 无精力条；走路、阅读与输入不耗游戏时间。

## 建议第一次尝试的路线

选择“开始新的一天”后，在登记亭找许舟报到；到道具间找陈叔做场务，实际把箱子搬到指定区域并交接。然后到咖啡馆买小礼物，等到 08:40 做上午咖啡班，按客人要求完成三份订单。可去码头记下铃声，为今晚准备话题。

T 打开日程：到 12:00 完成午间用餐与休息，14:00 继续自由活动；20:00 进入 Z 的手机直播。发送弹幕、送出背包里的礼物，或自愿报名随机文字连麦。每次“继续节目”推进 40 分钟；22:00 看完节目后，确认结束这一天，到 23:00 显示结算。

也可以购买材料并选择工作台教学，做自己的节目作品；它与上午咖啡班的窗口冲突，因此要作取舍。

## 当前边界

这版验证白天准备如何影响晚上交流。Z 使用读取本局事实的离线作者回应与四表情图集，观众为本地模拟；尚未接入联网大模型、真实 Live2D、语音或环境音。不是完整 21 天或完整 Chapter1；不会在第一天自动发出后续私人邀约。
