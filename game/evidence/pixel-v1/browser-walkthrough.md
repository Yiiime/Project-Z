# 浏览器连续走图记录

2026-10-12，最终像素地图制作回合。使用 Codex 内置浏览器运行本地 Web 导出，1280×720 画面。测试端口 61328 与日常试玩端口 61327 分开，不覆盖日常浏览器存档。

通过真实鼠标和按键（不是设置角色坐标）执行：

1. 点击“开始新的一天”及“开始探索”。
2. 持续 W/A 走到许舟附近，看到 E 键帽和对象名称；E 打开许舟对话。
3. Esc 退出，持续 A/W 穿过街区，到咖啡馆前；E 进入室内。
4. 从门口向上行走，被桌椅组合阻挡，未穿过桌椅。
5. 向右绕过桌椅，再向上到柜台前；E 打开林乔工作与小店面板。
6. Esc 后按 M，看到咖啡馆实际布局与柜台前的玩家位置。

全程未确认计时活动，HUD 仍为 07:00、40 金币。浏览器 console 的 error/warn 查询为空。之后重载最终导出确认标题界面加载正常；最后一轮只涉及陆岑站位、门口热点及 E 图标避让。

另有 `capture_pixel.gd` 输出的 13 张原生截图，使用定位夹具，不能把这些静态图片误称为连续走图。

本记录没有验证整座岛的每个边角，没有测试不同浏览器/设备，没有对《动物迷城》实机录屏测量移速、镜头阻尼、动作帧或交互距离，也不代表用户已通过美术验收。
