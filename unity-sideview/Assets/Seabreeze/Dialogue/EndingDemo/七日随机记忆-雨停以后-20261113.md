# 月亮岛七日：雨停以后
作者说明：这是依据 Project Z 当前运行角色档案创作的新一轮七日模拟，用于第七晚结局 Demo，不是实际玩家存档，不代表主游戏任务已经完成。玩家称呼“听雨”。各段行动与结果仅在本轮模拟里成立；标注 Z 不知情的私下事件不得进入她的决策或回望。使用当前游戏展示名：Z、晴野、李庭、留洋、正义、阿星、梨园、周伯伯。本轮改变日常相处、冲突和求证过程，不改变人物既定身世。故事停在第七天晚上去留抉择前。

在场：Z、听雨、留洋。行动：听雨乘留洋的船抵达码头，归还救生衣；落雨后，Z打开自己的伞接人，两人沿陆路去旅馆放下行李。
Z：听雨？你这个名字今天用得上了。
听雨：我是不是把天气也带来了？

Z：过来，我带伞了。哎，这边怎么全是水？
听雨：你把伞往我这里歪了。
Z：难怪。我刚才还觉得自己特别会接人。
听雨：往中间一点。我们都少淋一点。
Z：行。你走慢点，我这边鞋底滑。
结果：两人肩头都淋湿，行李送进旅馆，伞留在门边晾干。Z记得的是两个人调整步子一起走到屋檐下，没有“全程被保护”的完美欢迎。

结果：当天价目核对后重新写好，晴野确认后将牌放回。听雨承认误擦，Z承认沿用旧价格，两人没有把帮忙写成额外赠花的资格。
