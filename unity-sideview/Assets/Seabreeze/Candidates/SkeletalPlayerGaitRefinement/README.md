# Gait Refinement — 后伸保持与早期摆动候选

2026-11-04。独立候选，基准为 `SkeletalPlayerTrailingSupport`。没有替换正式 Player，没有修改原始候选、PSB、骨架或蒙皮权重。

## 预览

在 Unity 菜单选择 **Seabreeze → Candidates → Gait Refinement → Play Comparison**。

- 左：新版「后伸保持」；右：上一版「后侧支撑」。同一物理父节点提供相同实际位移，两个模型 scale 均为 1。
- `1`：1.65；`2`：2.2；`3`：4.2，仅作旧速度参考。
- `A/D` 或方向键：手动行走，松开停步；`空格`：自动/手动切换。
- 默认自动行走 3 秒、停步 1 秒，再反向。正式游戏入口未改变。菜单临时指定候选启动场景，退出 Play Mode 后恢复。

场景：`GaitRefinementComparison.unity`。
Prefab：`Prefabs/PlayerRigCandidate.prefab`。
如需重新生成，退出 Play Mode，使用同级菜单 `2. Build Idle and Walk`，然后 `3. Build Comparison Scene`。

## 本轮修改

1. `CandidateMotionBuilder.cs` 的 `SoleTilt`：55% 由 −10.5° 改为 −8°，55% 两侧切线均为 −185°/归一化周期。50% 和 60% 仍为 −4.5°、−24°。这使后伸保持更久，同时避免仅改关键值后出现先伸膝、再突然屈膝的回折。
2. 早期摆动的屈膝地标：64% 44°→41°、68% 56°→50°、72% 58°→54°；62% 36°和78% 46°不变。对应高度仍由既有两段腿几何产生。
3. `swingX`、骨盆曲线、步幅1.65、支撑率60%、前掌滚动起点38%、头部/手臂曲线全部保留。
4. 新目录、独立 GUID、命名空间和预览。`RigAnimatorDriver`、`RigFootContact` 与旧版只有命名空间区别；没有更换驱动/接触算法。

Walk 是连续 Transform 曲线，17 骨骼、51 通道、每周期160个烘焙区间；不是 Sprite 序列帧。原始 PSB/SpriteSkin 资源共用且只读。

## 已知限制 / 下一优先项

- 后伸保持带来取舍：50%–60%屈膝峰速由292→348°/s（1.65），386→464°/s（2.2），峰值移至约57%。曲线连续，但不是所有阶段都更慢。
- 原有触地附近仍有膝角速度尖峰，旧新基本一致；下一优先项是末摆动→承重的角速度过渡，不宜继续追求更大的后伸角。
- 保留的近/远髋点前后偏置约0.12014 world，使两个半周期膝交会相位仍相差约6个百分点。这是投影/绑定边界，本轮没有移动关节或修改蒙皮来隐藏它。
- 稳态目标无需抬脚或降低骨盆补救；停步仍沿用旧版 `LowerPelvisForReach()`。短停录制中，修正前最差余量−0.01526 world，通过降低骨盆约0.01983 world恢复可达，新旧相同。
- 最小可达余量只有约0.00269 world，属于窄裕量；不建议未经复查再拉长步幅。
- 这是一轮候选视觉与实际运行检查，不是完整测试套件，也未替换正式 Player。
