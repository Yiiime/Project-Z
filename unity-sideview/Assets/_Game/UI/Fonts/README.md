# Chinese UI font

- Source font: Noto Sans CJK SC Regular, downloaded unchanged on 2026-11-02 from https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
- License: SIL Open Font License 1.1; the upstream license is included as `NotoSansCJK-OFL.txt`.
- `NotoSansCJKsc-Regular SDF.asset` is generated with Unity TextMesh Pro: 64-point sampling, padding 6, 1024×1024 dynamic atlas, multiple atlases enabled.
- The atlas includes the initial interaction text. The source font remains referenced so later Chinese dialogue can add glyphs dynamically.
