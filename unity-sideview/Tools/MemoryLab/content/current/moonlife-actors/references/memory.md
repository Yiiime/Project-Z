# 私有记忆、信念与反思

每人独立存观察、交流、已知事实、关系、承诺与议程。世界事件可集中存，检索先按角色可见范围过滤，再排序；不可先检索全岛秘密再希望模型忽略。

source_event_ids保留原始来源。听到一句话是观察，话的内容为claim；事实核实与完成由引擎确认。反思只形成本人的inference，不新增客观事实，也不直接改别人知情。转述多次不升级验证。

自己先前说过的话也遵守这条规则。“我说过菜单递给你了”只证明说过，不证明递过；不能在下一轮用这句原话为自己作证。执行成功只确认对应动作的效果，wait成功或台词已显示不等于物品交付成功。玩家质疑时对照真实回执；没有完成依据就纠正原先说法，保留“此前说错并更正”的经历，不把双方争论升级成世界事实。

检索结合主题相关、近期、重要性，优先当前问题与未完承诺。不要只取最后几轮；重要旧错与关系不能被普通闲聊挤掉。没提供某段记忆不等于角色已忘记。家庭与成长叙事只沿用已启用的角色认知，不据此证明客观童年，不新写记忆机制。

反思由后台在积累了足够重要新观察后低频生成，只引用本角色确实观察的条目，保留来源；不在每句回复链路再调用模型，不输出长内部思考。推断可被以后事实修正，但事实不因害怕或道歉消失。

承诺与完成分开。未完承诺可优先检索；明确完成后解除其待办状态，历史仍保留。memory_updates/knowledge_updates在NPC三部分输出中继续[]，由后台写实际观察和回执；反思入口有独立内部结构，不变成第四个NPC输出字段。

持续数据不放进Skill静态档案。当前角色文件是人格底稿，运行时数据库是本局经历；不同玩家会话互不共享。

自然记忆分别估计容易想起与细节清晰。角色此刻只获得记忆视图：细节清晰才看原文，模糊时看大意；直接线索可以唤起尚存细节，不能凭空补日期、数字或原话。职业、地图和既有关系是稳定常识，不因episodic记忆衰减而失去。

原话日志先持久化，整理在后台进行。NPC能用近期实际原话接话，不需要等摘要完成。反思引用个人经历／听说的原话证据，旧证据被更正后，相关反思待重审；查看观察室不强化回忆。生成但未实际说出的提案不属于亲历，旧时间线未提交结果不可写回。
