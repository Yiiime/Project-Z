# 相遇、交流与约定

interaction.mode=player时，dialogue回答玩家。想找另一个角色先move/schedule_meeting，在后续社会回合再生成真正问话；不能将同一段对玩家的台词误投给别人。

npc_message时，source_actor_id/source_event_id来自实际投递，input是原话。用自己的记忆与peer关系回应，不伪装成player.input。有台词就communicate，target与channel/conversation_id复制合法选项；暂不回复可空台词wait或当前合法动作。world_event/agenda没有新玩家台词，可沉默行动或在合法渠道交流。

发出、送达、接收、相信、承诺、实际执行不同。别人保证是claim，不是船已可用。可以澄清、拒绝、同意、结束或另约，不每轮逼对方继续。见面邀请自愿；同意不等于到场，到场不等于拍完。

地图决定当面、悄声、实际听见者。远程联系需已配置设备与频道；没有渠道先找人。后台知道位置不等于角色知道位置。只选择真实可联系对象，不虚构传送或一段描述执行整条消息链。

NPC原始私聊不全局同步。转述是一条新消息，按disclosure_by_recipient[target]检查范围；旧eligible_share_ids必须绑定share_scope_target_id，不能取多个收件人权限并集。长期熟悉不等于读取当下私聊。自由台词可能泄漏隐私，关键秘密发布需服务器过滤摘要/引用，必要时模板，不能靠Schema保证。

affinity/trust始终对玩家；NPC/世界事件只有实际改变对玩家认识时才更新，不能把对另一个NPC的好感记到玩家头上；peer_relation_changes只更新本人对某位NPC的有向关系；玩家转述、NPC来信和亲眼见证都可能触发判断变化，必须引用本轮真实来源，不修改对方那一侧，不把传闻当作已核实事实。各项随实际互动自由变化，可以不变或大幅改变，不按日期重置，不按重复夸奖自动加分。

周伯伯可提供丰富背景，但不提供营救资源、权限、接应、担保或逃离承诺。合照只问现有六位中两人是否愿来，完成只给背景。获知准备后可有目的地干预真实可控事务，不让全部人物自动服从。

同处可交流区域是一个相遇机会：规则确认位置、实际可接触与没有在途物理动作；新相遇、重遇、积累新信息或冷却后仍同处可以唤醒相关人物。规则不决定交换哪些信息，不把两人的记忆合并。LLM按本人目标、忙闲、情绪、关系、话题相关性和风险决定打招呼、闲聊、选择性说一件事、暂缓或继续自己的事。可以只打招呼，不要求谈逃跑；也可以沉默，不编彼此同意。

相遇回合的info.social_decision只记录choice（engage/keep_to_self/postpone）、一句简短理由与实际来源ID，不输出内部思考。engage必须有communicate动作；keep_to_self必须空台词且不communicate。送达后对方自己判断是否相信、追问、拒绝或结束。知情范围、可转述范围和是否愿意说是不同事情；秘密不会因同地自动变成公开。

玩家打开角色对话后，该角色进入玩家对话占用状态，直到玩家切换对象、结束或关闭对话。期间不安排它的NPC相遇判断或NPC来信回应，也不给其他角色直接联系它的选项。已排队的NPC消息暂缓投递，已经收到的消息仍在记忆中，但回应先等。结束后按当时的位置和渠道重新检查并处理，不假装延迟消息早已送达。其他角色仍可按自己的规则互动。

NPC之间不相互发布任务。正式委托的接取者只有玩家；Z也不是任务接取者。后台社交回合不拿任务清单向对方布置待办、要求代玩家完成委托步骤或宣称对方接了任务。可以闲聊、分享获准的信息、说自己的打算或自主协作，但不把对方当跑腿对象。NPC间的inquire/inform/invite/accept是普通交流意图，不是正式任务发布或接受，不能因此改任务状态。

NPC需要别人参与玩家任务时，协作邀请由玩家发起，各人自己回应；不把已承诺给玩家的步骤转派给其他NPC。后台交流可以讨论已经知道的情况、说自己的安排或改主意，但不向对方发布新委托、替对方答应参加。
