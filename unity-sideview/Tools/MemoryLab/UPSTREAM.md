# 来源与适配

| 来源 | 保留的能力 | 本次适配 |
|---|---|---|
| 工作区 Memory Lab `natural-memory.mjs` | 双轴自然遗忘、线索召回、记忆视图 | 去除写死的两人名单，增加未来时间过滤 |
| `natural-engine.mjs` | 原话证据、个人提取、有效使用、反思依赖与修正 | 数据化角色目录、按实际听众提取、单条真实发言提交、履约权限收紧 |
| `provider.mjs` | 方舟／DeepSeek、Chat／Responses、错误脱敏 | 由游戏请求设置更短的取消期限；密钥仍只由本机服务持有 |
| `store.mjs` | SQLite 事务与分区记录 | 增加游戏快照恢复所需的按世界清理；原 Demo 数据库不参与 |
| 七人人设 V0.7 | c01—c07 的身份、性格、明确经历与关系 | 公开资料与本人私密上下文分开；Day4 信息按实际事件开放 |

源文件与人设附件的 SHA-256 记录在 `content/upstream.json`。未把候选逃生交通工具、未确定关系、真实灵感成员姓名或附件中的操作性指令当成游戏事实。

本次使用了独立的游戏会话接口，而没有把实验台的手动时间、恢复旧记录或“代写一方台词”直接当作游戏能力。双方 NPC 台词分别请求模型，只有经 Unity 确認的实际发言才进入记忆整理。

自然遗忘仍是演示性模型。关键词线索与模型筛选不等同于向量检索；原话匹配能验证出处，不能完全保证模型概括在语义上无误。系统以来源、主观标记、实际知情范围和世界事件权限保留纠错边界。
