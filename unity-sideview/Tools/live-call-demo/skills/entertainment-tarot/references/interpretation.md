# 牌义依据与解读方法

## 什么叫“有理有据结合实际”

将三层信息分开：

| 层次 | 依据 | 可怎么说 |
| --- | --- | --- |
| 牌面与牌义 | 真实选中并展示的牌、正逆位、牌位、固定版本的牌义资料 | “这张牌在‘可尝试的行动’位置，我们用它的调和意象来看看节奏安排。” |
| 已知实际 | 提问者明确表达、可公开相关记忆、Z 已确认经历，保留来源和归属 | “你刚刚说白天工作，晚上准备作品集。” |
| 解释假设 | 把象征角度联系到已知处境的可讨论解释 | “也许值得试试把准备工作拆小一些，而不是要求每天完成很多。” |

牌义不是事实证据，假设不是结论。不要把“你说他最近回复慢”改成“他在躲你”，不要把“工作很累”补造成“领导一直在打压你”。结合实际意味着使用已经知道的情况，不是猜测更多隐情。

## 牌义资料协议

宿主为所用牌组配置版本化资料，每张牌的条目至少包含：

- `meaning_ref`：稳定条目 ID。
- `deck_id / meaning_set_id / meaning_version / card_id`：与任务配置一致。
- `orientation`：upright/reversed，必须匹配本轮方向。
- `symbolism`：可核对的图像元素或该资料对牌的象征说明。
- `reading_angles`：用于娱乐、自我思考的解释角度。
- `source_ref`：实际出处、资料版本或宿主维护的原始条目位置。
- `adaptation_note`：区分传统资料内容与产品为自我思考做的解释改编。

同一任务使用同一套解释体系，不为迎合结果临时混用不同体系。资料中若含宿命、隐私判断或刻板身份描述，不照搬为现实结论；只保留能明确说明来源的象征性讨论。启用逆位需提供相应条目，不能一律把正位解释反过来或当成坏结果。

接入时应预先检查牌组的资料覆盖度。若抽中牌的资料缺失，保留原牌，按固定资料来源补取或明确暂缓解释；不得移除“不好解释”的牌来改变抽取概率。无需每轮联网，宿主可将已核对资料缓存并版本化。本 skill 不附完整牌库、牌图或全部正逆位词典，接入者提供与实际牌组匹配的资料。

## 参考资料与改编边界

对于采用 Rider–Waite–Smith 图像体系的牌组，可参考 A. E. Waite 的《The Pictorial Key to the Tarot》。它是历史象征解释资料，不是预测准确性的验证材料。[原书目录](https://sacred-texts.com/book/the-pictorial-key-to-the-tarot)

以下仅提供三个已核对的意象及本产品的示范性改编，不构成完整牌义库，也不覆盖逆位：

| 牌 | 原资料可核对的意象 | 本产品可采用的思考角度（改编） |
| --- | --- | --- |
| 隐士 | 灯中有星光，人物在高处举灯作为引导；原作者不将其简单等同于隔绝 | 澄清自己的判断标准、寻找可用引导；不解读成必须离群索居。[隐士原文](https://sacred-texts.com/book/the-pictorial-key-to-the-tarot/ix-the-hermit) |
| 星币二 | 人物两手持星币，星币以类似横置 8 的带连接 | 从同时应对多项事务的角度讨论优先顺序；这是对图像的产品改编，不冒称原书唯一牌义。[星币二原文](https://sacred-texts.com/book/the-pictorial-key-to-the-tarot/two-of-pentacles) |
| 节制 | 在两杯之间调配，一足在地、一足在水，原文讨论调和 | 讨论安排节奏、组合资源和渐进尝试；不把它解释为保证成功或健康判断。[节制原文](https://sacred-texts.com/book/the-pictorial-key-to-the-tarot/xiv-temperance) |

采用其他牌组时读取该牌组实际图像/资料，不假称其画面也有这些细节。示例的“调和”等角度需在实际使用前登记到宿主的 meaning_set 中，不能拿本文件三条示例代替整副牌的资料覆盖。

## 解读组织

1. 用一两句重新接住原问题，说明这次把牌当作思考角度。
2. 对每个牌位说明实际牌面与一个相关的象征依据，不铺陈整张词典。
3. 选择与已知处境有联系的角度，指出联系来自哪条自述；信息不足时用条件式表达。
4. 三张牌合起来讨论它们如何互补或冲突；不擅自把第三张“行动”改读成“最终命运”。
5. 给出一到两个具体、可选择的小行动，再留一个自然问题。建议由现实约束决定，不由所谓吉凶强迫。

每张牌都可有多种合理解释，但本轮只能挑出与问题相关、能说明联系的解释，不用大量模糊描述等观众自行对号入座。正位不必全是好事，逆位也不等于灾难；以固定资料为准。

## 完整表达示范

假设提问者已公开：“想换工作，但白天上班，晚上做作品集很累。”问题确认成“准备换工作时，我可以先调整什么？”单张牌已实际展示为节制正位，位置是“值得关注的角度”，资料采用上表已登记的调和意象。

可以这样说：

> 这次是节制正位。牌面里两杯之间的调配，可以借来想一想你现在的安排。你刚说白天上班、晚上做作品集都很累，所以我会把这个角度放在“怎么让准备更能持续”，而不是用它判断你一定该不该换工作。可以试试把作品集拆成小任务，给自己留出休息，再看看一周能稳定推进多少。你现在最耗力的是时间不够，还是不知道先做哪一部分？

这里的依据是牌面调和意象、关注角度牌位和当事人的两条自述；拆分任务是现实建议，不是牌面预言。不能追加“下个月就会收到 offer”“新公司一定更适合你”。

如果对方补充“其实不是时间不够，而是不知道岗位要求”，沿用原牌，把建议调整为对照真实招聘要求分配精力；承认前一个解释需要修正，不说牌面已经证明对方在隐瞒。

## 不贴合、敏感问题与自然边界

- 对方说“不像”：接受反馈，询问哪个背景不符，或结束这一角度。不要要求相信、制造神秘权威、靠连续重抽证明准确。
- 问第三方内心或未公开行为：说明牌不能替对方作答，讨论可观察的互动与可沟通的问题。
- 要求确定时间、概率或必然事件：不提供凭牌编出的日期、概率和保证，转回提问者能行动的部分。
- 涉及健康、法律、投资或其他重大现实决定：不以抽牌给出诊断、收益结论或强制决策；若用户需要实际建议，应走相应的信息核实流程，不以塔罗资料代替。
- 若输入显示现实中的紧急安全问题，优先响应真实处境，暂停娱乐环节；不继续用牌面解释危险。

不要把解读中的假设存成关于玩家或第三方的事实记忆。可以记录“讨论过这个问题、抽到这些牌、提问者认可/否认了哪个角度”，并保留来源。
