# 原生直播接入验证

验证日期：2026-11-04。环境：Unity 6000.3.27f1、URP 17.3.0、macOS Metal、Node.js 25.6.0。
对照基准：Z.zip 中最新版 z-live-public，桌面 1280 × 720。

## 已运行

- `node --test tests/session.test.mjs tests/http.test.mjs`：18 项通过。覆盖会话和 HTTP 契约、消息回执、选牌暂停与整场暂停隔离、连麦等待与暂停下麦、环境配置优先级、语音授权错误安全传递。
- `tools/team/z check`：通过；包含服务回归、仓库规则、资源 GUID 和 C# 语法检查。
- Unity CLI 编辑器编译及独立后台 Play Mode：通过。实际从手机按钮进入直播，验证连接、设置弹窗和返回、原画切换、文字发送及回执、塔罗展示回执、绘画完成回执、展开和恢复、退出清理与重复进入。退出后 timeScale 为 1，无直播对象残留。
- 真实 DeepSeek 返回有效回复。真实 Vivi 合成音频在 Unity 中解码、通过 AudioSource 播放并收到 completed 回执，modality 为 audio，fallbackReason 为空。后台验收期间本机音频输出静音。
- 真实 ASR：将 Vivi 合成音频转换为 PCM16LE / 16 kHz / 单声道后识别成功，文本为“晚上。好，今天的月亮很好看。”。
- Web 与 Unity 同尺寸截图对照：Web 舞台约为 x=15.30、y=66.71、宽=937.77、高=588.29；Unity 为 x=15、y=67、宽=938、高=588。已检查角色构图、聊天、设置、原画、塔罗、绘画和展开画面。
- 绘画闭合路径已通过真实渲染确认；原生头像、麦克风与原画图层使用基准 Web 资源，Unity 资源配套 .meta。

本地验收截图与结果位于仓库内被 Git 忽略的 `local-materials/z-import/outputs/Web原生对齐验收/`，包含 `web-live.png`、`live.png`、`real-conversation.png`、`settings.png`、`manga.png`、`tarot.png`、`drawing.png`、`expanded.png`、`result.txt` 和 `voice-result.txt`。这些文件为本机验证证据，不随 Git 分发。

自动化回归使用隔离数据和模拟供应商，不调用付费服务；真实供应商联调单独执行。Unity 运行验证使用临时入口和独立存档目录，临时入口不随交付保留。密钥与本机连接凭据不提交。

## 验收边界

- 真人麦克风权限、收音效果与持续连麦体验仍需在本机手工验证；ASR 合成音频验证不覆盖这些条件。
- 后台 Play Mode 覆盖编译、程序运行和渲染；尚未完成用户完整手工试玩，也没有构建独立 Player。
- 桌面布局与主要交互已对照；字体渲染、原画微动和原生平台控件存在平台差异，尚未完成全部场景逐像素一致性验收。移动端竖屏未纳入本轮验证。
- 形象可切换原 Web 同源的 Haru 官方示例与 Z 原画。
- 曲库已接入版本和片段状态查询；整曲资料下载、网易云适配、歌词自动对齐及其管理台由独立资料模块负责。
- 动态唱歌的生成接口支持明确单段；整首歌曲与模糊片段会要求补充说明。人工试听通过后才能排入直播。本轮验证语音对话，未重新生成唱段。

PR 保持草稿，等待用户手工体验验收。
