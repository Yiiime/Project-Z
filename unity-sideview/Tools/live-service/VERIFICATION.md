# 原生直播接入验证

环境：Unity 6000.3.27f1、URP 17.3.0、macOS Metal、Node.js 25.6.0。

## 已运行

- `node --test tests/*.test.mjs`：28 项通过。覆盖会话重启与旧回执、连麦打断与挂断、ASR 最终结果与取消、HTTP 鉴权和幂等、重复进入、歌曲审核与缓存、试听与直播回执隔离、动态唱段的原生播放回执、曲库片段状态。
- Unity 编辑器实际编译：通过。
- `tools/team/z check`：仓库、资源 GUID 和 C# 语法检查通过。
- 独立后台 Play Mode：手机按钮进入直播、暂停探索、Live2D 初始化、连接本机服务、发送文字、读取服务端公开消息、渲染直播界面与点歌面板。
- 原生试听：已观察到 AudioSource 实际播放并完整结束已有 32 秒唱段；本机输出静音。这里只验证播放链路。
- 返回探索：已确认直播对象和专用相机释放、游戏音频状态恢复、输入阻塞解除、玩家位置保留；通过游戏运行帧注入移动输入，角色从 x=-8.00 移动到 x=-4.12。第二次进入与退出后仍保持单个直播对象，结束后无直播对象或相机残留。
- UI Toolkit 输出 1280 × 720 截图已检查，角色、背景、聊天及点歌面板可见。

运行验证使用临时入口和独立存档目录；临时入口不随交付保留。测试使用隔离的 SQLite 数据与模拟供应商响应，不调用付费服务。

## 验收边界

- 没有配置真实 DeepSeek、Vivi 和 ASR 密钥。真实生成质量、真人麦克风输入、系统麦克风权限和连续连麦体验需要配置后验收。
- 后台 Play Mode 与截图检查覆盖程序运行和渲染，尚未完成用户操作下的完整手工试玩，也没有构建独立 Player。
- 当前展示模型为随原生工程提供的 Haru；专属 Z 模型需要另行提供。
- 曲库已接入版本和片段状态查询；整曲资料下载、网易云适配、歌词自动对齐及其管理台仍由独立资料模块负责。
- 动态唱歌的生成接口支持明确单段；整首歌曲与模糊片段会要求补充说明。人工试听通过后才能排入直播。

PR 保持草稿，供配置供应商能力并完成手工体验后验收。
