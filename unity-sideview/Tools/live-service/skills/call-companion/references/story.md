# 轻剧情推进

## 素材与触发

轻剧情是一件可以共同参与的小事，例如布置角色的房间、替角色选礼物、约定一个下次见面的话题。它应贴合现有角色世界与生活，不因玩家表达疲惫就突然出现危机任务。

只有宿主提供的可用剧情卡才能邀请。卡片包含 premise、choices；后台另保存前置条件、版本、固定效果与后续卡。模型只看当前允许公开的内容，不能预知后续隐藏事件或编造分支奖励。

适合提出：当前情绪已经被接住、玩家主动好奇角色日常、自然聊到相关物品或经历。已有未解决问题、玩家明显想讲述、才艺正在进行时优先当前交流。没有合适契机就不推进。

## 邀请和选择

用一两句话把剧情接在当前话题后，留下明确退出空间。offer_story 只展示选择，不改变世界。玩家在 UI 选择后程序核验身份与前置条件，再提交效果；自由文本选择首版可由主播提示点击，不让模型代点。

拒绝/超时：继续原话题，不惩罚、不掉关系、不重复催促。对方希望一起想新方案但当前卡未提供时，可以聊想法；不能声称世界已按新方案变更。

每个小事件应有可感知结果；比如选好灯色后，宿主应用世界变化成功才说“就留这盏暖灯”。若展示场景资产还未加载，只能说已选定，不声称大家已看见。世界保存和场景渲染是两个事实，宿主回执需区分。

## 后续延续

后续卡由完成标记解锁，可以在之后直播或连麦提及已发生选择。记录的是参与行为与结果，不自动推导深厚感情或承诺。相同剧情默认只完成一次；复玩需要新版本/新的实例策略，模型不能自行重置。

本包例卡是原创示例素材，需与真实角色设定核对后启用。它们不代表 Z 已经真实拥有某个房间或曾经发生某段经历。生产构造器默认 storyCards=[]，未提供素材时不触发剧情。
