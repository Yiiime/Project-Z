## 参考与检查

已查看根目录美术资产参考中的全部 7 张场景图和 12 张对话/事件/探索图；图片是视觉参考，未将图内文字当作任务指令。背景延续蓝色冷影、橙色暖光、手绘建筑植物、水平步道和侧视构图。背景里没有人物或 UI；活动角色和提示由 Unity 独立渲染。

每张输出均进行了工具图像回看。背景地面基线约在图片顶部向下 83–84%，16:9。街道门中心约在图宽21.4%，灯塔信箱约68.6%，咖啡馆门约8.5%，收音机约22.7%，留言簿约73.3%。最终运行位置由主工程根据实际相机和场景宽度标定。

## 制作边界

背景仍是单张绘画合成图，不是把原画完全分解后的逐层 PSD；Unity 另行添加独立前景、粒子、光照和视差对象。白昼与傍晚是两张绘画变体，并非物理天空模拟。角色为可替换的基础精灵；走路只有四帧素材，其中两个迈步姿态较接近，动画精细度低于正式商业角色动画。轮廓个别像素存在生成透明边缘细屑，常规游戏显示尺寸下需由整合阶段继续视觉判断。没有声称人类美术验收。
