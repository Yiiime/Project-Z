草稿 PR #70；主线基线 ff82f9e。仅用于本地体验，不转 Ready、不合并。

## 体验路线

新游戏输入姓名 → 73.33秒先导片（期间准备直播） → Z 开场与一轮弹幕互动 → 点击礼盒并收下邀请 → 22.13秒登岛片（期间准备码头、Z 的单聊与语音） → 码头交流 → 跟随 Z 前往广场（途中准备介绍） → 与任意三个不同 NPC 交流 → 25.06秒烟花 → 黑夜自由找居民接一项迎新任务 → 首夜直播（NPC和虚拟弹幕） → Z 主动提出唱《晚安》 → 告别 → 电脑关机转场 → 第2天。

直播目标约150秒，包含歌曲与告别；实际网络与模型速度会影响时长。保持首夜先完成歌曲播放回执再正常收播；模型/歌曲失败不伪造完成，180秒起可有界收尾。歌曲沿用项目已审核的《晚安》完整副歌。
