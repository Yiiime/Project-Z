# show_case1 本地试玩

双击交付目录的 `开始试玩.command`，选择「开始游戏」。本包使用独立的 `Project Z show_case1` 本地存档目录。既有 Day01 包保留，草稿 PR #70 不发布、不合并。

## 本次变化

- 输入姓名时就准备带姓名的邀请函和抽奖视频。Z 开始说开奖台词时展示已准备好的动画，不再等整句播完才创建播放器。拆礼物和收邀请仍由玩家亲自点击。
- 合成画面提高到 2560×1556，姓名和接待人文字单独高清渲染，修复首帧布局未完成导致姓名层为空的问题。原视频为 1280×778，因此底片细节仍受原素材限制；未伪称更高分辨率原片。
- 首夜优先处理玩家消息，每轮只挑少量近期弹幕，免去等待 NPC 预回复的步骤；语音支持流式播放。NPC 与虚拟观众同时保留。
- 聊天更聚焦当天实际公开经历：认识新朋友、码头见面、一起前往广场、介绍朋友和烟花。未发生的经历不编造。
- 从首句实际播放开始聊天约 60 秒；有待回应的玩家消息时先回应，安静下来后用指定转场句「给大家唱一首《晚安》，祝大家晚安。」接歌。转场不再等待模型生成或额外一轮虚拟弹幕，但仍经过事实审阅及真实语音播放。歌曲完整播放后简短告别，随后电脑关机转场，不再凑满旧版 150 秒。
