# 游玩与验收指引

直接在 Unity 打开 `Assets/Seabreeze/Scenes/Street.unity` 并 Play。游戏会自动读取本机进度。需要重新体验开场时，按 Esc →「重新开始这一天」→ 确认。

这是没有战斗的一天短篇。可以在街道左右走动，靠近人物、建筑入口和带有微光的物件后按 E。右上角提示是当前已知线索；J 日志会保留经过与随身物品。M 地图可以直接前往其他场景，地图路线和场景入口都有效。

时间不会在阅读时流逝。长椅、海堤长椅与咖啡可以推进一个时段；夜晚休息进入第二天。错过陈伯的白天时段仍可从咖啡馆留言本获得相关线索。三个结尾都允许继续散步、查看日志与回看当天记忆。

## 基础验收路径（含剧情线索）

1. 阅读开场，A/D 或左右键移动，空格跳跃。
2. 沿海边走到右侧长椅，查看旧明信片。
3. 走回咖啡馆入口按 E，进入室内并与阿遥交谈。
4. 回到街道与陈伯交谈，从三个回答中选择一个。
5. 在长椅休息或咖啡馆喝咖啡，让时间到傍晚。
6. 沿街道右端入口或地图前往灯塔海堤，与澪交谈。
7. 查看蓝色信箱，完成当天的故事；结尾会随之前的回答变化。
8. 打开日志回看经历，关闭后仍可探索。退出和重新进入会恢复地点、位置、时段与对话进度。

没有失败倒计时，不必严格按这条路线行动。
