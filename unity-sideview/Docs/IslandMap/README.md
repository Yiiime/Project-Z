## 空间标定与生成

`Editor/IslandMapBuilder.cs` 是本次地图生成入口：菜单 **Seabreeze → Island Map → Build Current Map Assets**。它只重建地图地理、出入口、相机和背景，不生成 Player、NPC 数据或剧情数据。每张图有独立地面像素基线；世界宽度取真实图宽 / PPU，而非统一 36 单位。

- 室外 120 px/unit；室内基准 165 px/unit，并按图高 / 1152 归一，以免同构高清室内导致人物比例突变。
- 保留完整图片纵横比；导入上限 8192，居民街长图保持 7505 px，不压成 2048/4096 后继续使用原坐标。
- 相机根据实际场景宽高约束，当前逐图预览采用 16:9。
- 地面位于前景通行带。桌椅、台阶、植物是烘焙进背景的图像，未伪造家具可绕行或爬楼能力；上下移动由路口切换实现。
- 采用单张原图与轻度时段色调，不再由旧 `SceneAtmosphere` 加载 `street_day` / `cafe_day` 把新图换回旧图。

`IslandMap.asset` 为将来地图面板提供地点、来源文件、宽度、室内标记、路由与返回落点。同一配置生成场景和目录，避免面板与通路分别猜测连接。

## 生命周期与保留内容

所有路由继续经过 `GameSession.TravelRequested`，保留既有 NPC 记忆、对话取消与位置捕获事件。转场开始立即阻止重复请求和输入、停止物理模拟，落点同步到 Rigidbody2D 与 Transform，再恢复模拟。自动出口的落点位于目标入口内侧，避免落地即弹回。

生成器会检查 E 点与同侧自动出口的安全距离。首次运行检查发现码头下行点过近后，已移到安全区域，重新验证。

保留 Player、移动参数、序列帧动画、NPC/对话/剧情代码。原 Street/Cafe 场景的剧情交互 ID 保留；只有与新图明显错位的环境交互空间位置校准。旧无关场景生成器的枚举循环限制为原三场景，再调用地图生成器，防止新增地点被错误生成成灯塔模板。
