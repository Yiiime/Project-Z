# 开发记录 · 海风捎来的信

## Phase 1 — 项目检查与初始化（2026-11-03）
- 原始目录只有 `美术资产参考`，没有 Assets、Packages、ProjectSettings，没有可复用代码。
- 使用本机 Unity 6000.3.27f1（6.3 LTS），从随安装提供的 Universal 2D 模板提取渲染设置。
- 依赖：URP 17.3.0、Input System 1.20.1、UGUI/TMP 2.0.0；没有引入 Cinemachine 或额外对话框架。
- Unity Pipeline 0.9.1-exp.1 仅用于本地编辑器开发验证；无生产服务、无远程运行要求。
- 采用 Noto Sans SC（OFL）中文字体，TMP Essential Resources 来自 Unity 内置包。
- `美术资产参考` 原文件不变；新资产独立存放在 `Assets/Seabreeze/Resources/Art`。

## Phase 2 — 核心玩法（已实现）
- 独立玩家控制、交互器、跟随相机、场景导演、NPC 出场、时间与剧情系统。
- Rigidbody2D 加速度/刹车、地面 Cast、短跳跃输入缓冲及离地宽限；全程 2D 碰撞。
- Street / Cafe / Lighthouse 独立场景，场景间保留会话和存档；无 3D 几何。
- 时间采用主动推进；NPC 按时段出现，不让阅读时间产生截止惩罚。

## 保留的原型限制
- 背景建筑、天空、远海未拆成完整可独立编辑的生产级美术层；现有独立视差用于海面微光和前景。
- 角色为基础精灵动画，两个迈步姿态较近，跳跃复用抬膝姿态；没有完整骨骼、面部或口型动画。少量小物件仍是程序绘制。
- 夜晚以已有绘景加环境染色表现；咖啡馆窗外没有单独的夜景绘画。天气实现晴天/薄雾，尚无完整天气粒子系统。
- 这是一日短篇的可玩原型，非商业成品；没有用户试玩验收记录。
