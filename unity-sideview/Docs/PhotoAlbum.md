# 小岛留影

在探索、对话、手机页面或原生直播中按 **P**，会把当前完整画面存入手机「相册 → 照片」。拍摄不会推进游戏时间；手机暂停状态也可拍摄。正在文本框输入时不截获 P，先退出输入框再拍照。启动首页不拍摄。

相册列表显示真实缩略图；打开照片后可查看大图、收藏。照片与共同经历的文字记录分开筛选，收藏共用已有的存档逻辑。文件丢失时保留记录并显示读取失败提示，不用别的图片冒充。

## 数据与生命周期

- `PhotoCaptureService.Initialize(session)` 在 Bootstrap 中初始化一次，监听按键并在 `WaitForEndOfFrame` 后抓取实际游戏画面。每次拍摄有 0.8 秒冷却，避免按住按键产生连拍。
- 原尺寸 PNG 和最长横向 512 px 的缩略图存放在 `SaveRepository.PathOnDisk` 所在目录的 `Photos/<albumId>/`。相册标识是该存档持有的随机 GUID。重新开始使用新的相册；旧文件不被覆盖。
- `PhoneSaveState.photos` 只存图片文件名、日期时段、地点、分辨率等元数据，不保存机器绝对路径。文件先写 `.tmp` 再移为最终 PNG；完成后保存游戏状态。
- `PhotoImageView` 按 UI 生命周期解码、释放纹理和 Sprite，缩略图列表不加载全分辨率照片。大图独立持有自己的纹理，页面后台刷新不会把大图资源销毁。
- 截图先完成，随后显示保存提示，提示文字不会出现在它对应的照片内。真实存档与照片均不纳入 Git。
