# 第七晚结局：主游戏接入

当前结局页已加入「上传 / 更换记忆文件」。确认上传后自动生成并同步到原生演出，支持本局后续真实经历、生成进度和上一份结局回看。使用和验证边界见 [记忆上传说明](EndingMemoryUpload.md)。

入口属于当前 `GameUI`：探索 HUD 左下角 **第七晚结局 →**，手机首页 **第七晚 · 进入结局**，以及暂停菜单 **进入第七晚结局**。任一按钮直接进入主游戏 Canvas 内的原生结局界面，不打开浏览器或独立场景。

进入结局时，游戏结束当前交流、同步记忆、暂停地图输入。退出后恢复地图控制。长文支持滚动。点击「继续」或按 E、空格、Enter 可以往下读，Esc 返回小岛。

完整七日演示有两页回忆。第一页回看第 1 至 3 天，第二页从第 4 天的转折讲到第 7 天。内置故事里玩家叫「字小节」，上传文件可以另取名字。每页由 Z 讲几件关键经历，空一行接她的感受，整句依次淡入。「看原文」可翻阅这一时段的全部原始经历。读完第二页后直接切黑，停顿 0.9 秒，再显示本局的选择。去留意愿和登船结果分别结算。

## 当前游戏与结局共享的内容

- 同一个 `MemoryLabClient`，同一个 `/api/game` 协议和模型连接；新增 `/api/game/ending`，主流程不依赖 4319 网页服务。
- 当前 `worldId/runId`、Z 的角色档案、关系与心情，以及该存档里 Z 真正看见、听见并可向玩家回望的事件。
- 原先生成的完整七日文件作为“直达第七晚”切片的预置经历，当前真实游戏经历补充进去；预置记忆和本局记忆在界面中注明数量。
- 只有 Z 知情且玩家在场或获准分享的真实事件可以进入这次演出。其他岛民私聊和未送达消息不会被引用。
- 结局结果写入当前 `MemorySaveState.seventhNightEndingJson`，对应结果也在记忆 checkpoint 的 `world.seventhNightEndings` 中保存。读档后可以回看原结果，回看不重新调用模型。

服务先让 Z 选择，再按每批 12 段生成知情经历的回望，核对记忆 ID。两页短稿和可回看的原文保存在同一份结局里。去留意愿与执行回执分别记录。相同请求只生成一次，读档或重开后的迟到结果不能写到新的时间线。

## 直达按钮的含义

这是用户要求的结局 Demo 快捷入口，把预置七日剧情与本局经历组合后演出。它保存结局快照，当前地图日期、位置、任务和关系仍由原游戏系统持有；不会把模拟文件改写成已经实际完成的主线任务或登船回执。正式七日主线达到终局时，可以沿用同一原生演出入口，替换掉预置部分。

## 运行

双击 `unity-sideview/试玩第七晚结局.command`，打开的是包含所有现有场景的完整游戏构建。构建菜单为 **Seabreeze → Ending Demo → Build full game with ending entry**，输出在 `Builds/IslandEnding/ProjectZ-IslandEnding.app`。应用保留原游戏产品名与存档位置，使用独立应用标识，方便同主工程构建区分。

启动器首次打开一个新构建时，会将签名校验过的应用复制到当前用户的临时目录，从那里启动。这样游戏载入原生库时无需访问「文稿」文件夹。再次启动同一构建会复用这份副本。

也可以在 Unity 中打开 `Street.unity` 并 Play，启动本分支的记忆服务。模型配置与已有岛民对话、直播共享，无需再配置另一套结局模型。

## 机制与验证

K04 保留具体经历与承诺对判断的影响；K12 保留理解、意愿和真正逃离分别结算；K11 保留同存档恢复与重复请求隔离。没有增加关系数值门槛。

后端回归已验证同世界记忆投影、秘密隔离、完整回望、重复请求、checkpoint 恢复和迟到请求拒绝。隔离的原生整局验证从 Street 启动，检查 HUD 按钮、Z Live2D、全部回忆翻页、手机回看、返回与读档；其结果在 PR 验证说明中记录。
