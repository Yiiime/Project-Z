# 小岛居民：对话、记忆与自主活动

十名 NPC 在现有 Unity 横版小岛中生活：留洋、晴子、梨园、伊停、周结、正义、星亮、Z、阿遥、陈伯。玩家独立。所有角色都是普通岛民，有自己的职业、性格、关系、模型对话与独立记忆；公司工作人员、演员、撤场安排和 Z 的 AI 身份设定已按用户要求移除。

## 开始试玩

1. 双击工程内的 `启动七人记忆试玩.command`。为兼容现有入口，文件名暂沿用旧名称；启动的是当前十人版本。
2. 模型配置页：`http://127.0.0.1:4330/settings`。已有本机配置继续有效；首次使用填写 API Key、Base URL、Model／接入点 ID，保存并测试连接。
3. A/D 或左右方向键走动，不再提供跳跃。靠近 NPC 按 E，NPC 会先根据记忆生成开场；你可以先输入草稿，开场完成后按 Enter 或“发送”回复，Esc 返回。
4. NPC 自己交谈时，台词自动出现在说话者头顶的气泡中，只暂停参与者。玩家无需点击或按键；其他 NPC 和玩家继续活动。
5. 长椅或咖啡推进游戏时段。到 Day4，十人和玩家收到“小岛将要毁灭”的公开公告，没有额外倒计时或公司解释。
6. 记忆观察室：`http://127.0.0.1:4330/memories`。可选择十名 NPC，查看自己的记忆、来源、反思依据和双轴数值。

Unity 编辑器入口仍是 Unity 6000.3.27f1 的 `Street` 场景；启动 `Tools/MemoryLab/start.sh` 后 Play。旧预写剧情模式保留 `-memoryDisabled`，不是当前十人试玩的默认剧情。

## 记忆与游戏边界

| 项目 | 当前规则 |
| --- | --- |
| 知情范围 | 只提供本人的人设和相关记忆；别人未听到的交谈不会自动共享。普通私人经历也不等于所有人都知道。 |
| Day4 | 公告由游戏日期触发，十人均接收，包括不在当前场景的人；按稳定事件 ID 去重。 |
| NPC 互聊 | 选择对象 → 检查可交谈 → 真实走近 → 停步相对 → 双方分别生成 → 自动头顶气泡 → 结束继续活动。 |
| 玩家开场 | E 键后先生成 NPC 的一句开场，不伪造玩家发言；每次会话只启动一次。模型决定问候、追问已确认约定或分享已有经历。 |
| 气泡 | 只要说话 NPC 出现在画面内就显示，与玩家距离无关；跟随角色、自动停留与分段，出画面、离场或切场景隐藏，不抢输入。 |
| 限制 | 首版同时调度一个会话；最多 6 句，同伴冷却 90 秒，接近限时 20 秒，会话限时 120 秒；慢模型在完整轮次边界收束。 |
| 发言与世界 | 生成结果先是提案；游戏实际提交发言才进入记忆。口头声称完成任务不会改变世界。 |
| 记忆与反思 | 亲历、听说、约定、主观看法分开。反思保留主观标记，不能自行变成客观事实。 |
| 自然遗忘 | “容易想起”和“细节清晰”独立变化，没有六天强制清空。 |
| 取消和读档 | 玩家介入、离场、切场景、载入或重置取消未说出的结果；运行标识与响应版本防止迟到结果覆盖新时间线。 |
| 未配置或失败 | 可以探索，显示连接／等待／失败状态，不使用固定 NPC 台词冒充模型。 |

## 旧进度迁移与备份

十人升级继续使用 `seven-memory-save.json`，不改原 `seabreeze-save.json`。旧七人人设快照首次载入时升级到 `personaRevision: 2`：

- 原始快照先写入本机数据库的 `game_archives` 备份表，不进入 NPC 上下文或观察室。
- 更新受旧设定影响的人设经历；移除旧内部通知、相关旧发言记忆及依赖它们的反思。普通交流和回忆次数保留。
- 补入新增角色自己的基础经历。只有旧进度已实际发布 Day4 公告时，才补齐新增三人的公告记忆，不向过去注入未来事件。
- 旧队列中已撤销设定的发言确认后跳过，不重新提取；新版本的正常用户发言不会按这些关键词过滤。
- 事件确认序号与重复回执保留。同一旧快照重复载入不会重复备份或重复公告。

交付前另做数据库与当前游戏存档的本地备份。模型密钥仅存在服务 `.local/model.json`，权限 0600；分享包不含密钥、数据库、真实存档、迁移备份或原始模型请求。

## 本机观察室

默认选择最近载入的进度，每 3 秒刷新，可暂停、搜索、按类型筛选。页面供开发调试，能看到记录原文；NPC 此刻能想起的内容另行展示。查看不调用模型、不强化回忆、不写数据库。

旧的未载入进度以新规则作只读投影，真正升级在游戏载入时完成。关闭游戏后页面仍可查看服务最后确认的记录，不把它宣称为实时在线状态。

## 验证边界

服务测试使用临时数据库和本机模型替身。Unity 流程使用隔离存档；模拟与真实模型报告分开。中文输入的自动验收注入 Unity IME 组合文本，不能替代用户的物理输入法体验。

当前检查：35 项服务测试、14 组模拟场景、8 组真实模型流程、6 组动作回归及 3 组未配置模型检查通过。覆盖自动开场、气泡画面范围、取消跳跃、十人、Z 立绘、输入、Day4、记忆与读档。直播外壳只连接隔离的不可用端点，本轮不宣称验证了真实连麦或唱歌。

真实模型、最终构建和独立启动结果以本地包 `Verification/openers-bubbles-summary.json` 为准；初次真实模型尝试的同步收尾超时保留在记录中。编辑器自身的 SearchDatabase 启动异常单列，不混入游戏运行异常。

## 从协作仓库取得模型

Z 的 `Model.asset` 由 Git LFS 管理。克隆或切换到此分支后，先运行 `git lfs install` 和 `git lfs pull`，再打开 Unity。LFS 指针不是模型内容；本地构建与画面验收使用完整模型。仓库快速检查可在指针检出状态运行，不等同于模型加载验收。

## E 键自动开场、无跳跃与头顶气泡（2026-11-07）

开场复用当前记忆召回，不新增任务系统。可核对的玩家约定优先提供给模型；NPC 自己的承诺、已兑现约定、第三方陈述和未确认提议分开。细节已模糊时只提供大意，不通过原始聊天记录把旧细节重新注入。

未配置模型时显示状态；连接或生成失败可“重试开场”，也可在模型恢复后自己先说。关闭对话、读档或离场会取消未说出的结果。正在等待开场时可以编辑草稿，发送在开场完成后启用。

气泡按主镜头画面判断，不再限制玩家距离；NPC 身体在画面边缘部分可见时也显示，气泡位置会限制在屏幕内。每次显示当前说话者，长文本自动分段。离开画面时隐藏，回到画面且当前台词未结束时继续显示，不重播已经结束的旧台词。NPC 彼此的听距、遮挡与记忆知情范围保持原规则；玩家看见气泡不扩大其他 NPC 的记忆范围。

跳跃冲量、空格/W/↑ 跳跃映射和操作提示已移除；水平速度、加减速、16 帧步态、重力、落地及场景通行保留。

本轮结果见本地包 `Verification/openers-bubbles-summary.json`，区分服务自动化、模拟场景、真实模型和独立启动检查。原有试玩数据使用独立备份与相同存档路径，测试不覆盖用户存档。

画面范围调整的补充验收见 `Verification/screen-bubbles-summary.json`：屏幕内超出玩家听距的新发言仍显示，离开画面后隐藏；实际记忆听众不受显示规则影响。
