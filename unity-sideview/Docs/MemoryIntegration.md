# 当前八人 Skill、自然记忆与 A2A 接入

角色以用户当前人设为准：Z、梨园、李庭、阿星、正义、小小晴、林序、周伯伯。内层输出是 `dialogue / action / info`，Unity 不再维护另一套普通岛民身份。内容源在 `Tools/MemoryLab/content/current/`，公开角色名册在 `Resources/Memory/characters.json`。

## 使用

1. 在 `Tools/MemoryLab/` 执行 `sh start.sh --background`，首次安装会解析声明的 npm 依赖。
2. 默认地址 `http://127.0.0.1:4330`，`/settings` 配置模型，`/` 为对话、动作、数值体验，`/memories` 为只读个人记忆观察室。
3. 使用 Unity 6000.3.27f1 打开主工程，运行 `Assets/Seabreeze/Scenes/Street.unity`。靠近NPC按E，Enter发送、Esc结束。模型未配置或失败时显示状态，不提供假NPC台词。
4. 新八人运行使用当前协议2的进度。旧十人人物快照不自动转换；如需历史迁移，先核对角色映射和原始证据，不能按名字相似或AI／公司关键词清除内容。

实际地图仍复用包内三个横版场景。`sceneId` 是Unity场景，`locationId` 是当前地图节点，`Resources/Memory/locations.json` 是已绑定的测试导航锚点。NPC知道完整静态地图，不等于所有地图节点已有Unity美术、入口或可执行路线；未绑定节点不提供移动动作。

## 记忆

稳定层包括姓名、职业、公开地图、已确认既有关系。个人经历使用availability（容易想起）与clarity（细节清晰）两轴衰减，当前线索可以唤起尚存细节。已核实知情、任务阶段和进行中协作另行延续，不被普通遗忘撤销。

近期实际原话与长期召回分开。原话先保存，提取、反思、回忆强化在后台执行，不阻塞即时回复。亲历、听说、主观看法、承诺和完成分开；反思有依赖和反例，旧依据更正后需要重审。查看观察室不会调用模型或增强记忆。

这是可调试的自然记忆模型，关键词与规则召回不是向量检索，出处核对也不能证明所有自然语言概括都正确。

## 空间 A2A 与占用

Unity提供实际可见、可达、空闲的候选，模型决定是否交流、找谁以及谈什么。发起者真正走近后，双方逐句独立生成；接收者可以拒绝或结束，最多六句后收束。距离、遮挡和频道决定真实听众；常驻工作地点不透露实时行踪。

按NPC保存占用：玩家和Z聊天时，Z暂停NPC交流；林序与阿星仍可相互交谈。玩家介入只取消涉及该NPC的会话。结束后恢复各参与者自身行动。

## 三部分与实际回执

生成结果先是proposal，不直接修改已发生记忆、数值或任务。Unity真正呈现台词后提交实际utterance，后台核对提案、角色、版本、对象和听众再提交状态。移动仍由`MemoryActionExecutor`执行实际可达锚点，并反馈成功或受阻；对话里的“完成了”不产生物品或任务结果。

界面独立展示Action／Info。NPC提出玩家任务后可接受或暂不接受；接受后可向当前NPC发起协作邀请，NPC自己选择参加、拒绝、改期或只承诺部分。正式任务不发给NPC，NPC不代玩家接取。玩家拒绝后，重提需要后续真实交流和明确新理由。

实际修理、物品交付等完整玩法触发器仍需游戏对象提供回执；`ConfirmTaskStep`是可信执行器接入口，不是模型可调用的通关函数。

## 顺序、取消与读档

Unity发言、观察、剧情消息、时钟、任务响应／协作邀请／任务回执、动作回执共用一个持久outbox：稳定id、连续seq、明确day/period。后台意向判断与记忆整理不占用该序号。

切换、取消或读档后，旧生成不能写回。已经实际呈现但还在outbox中的原话，先完成同步再取消；读档后可按保存的批准提案核对重放。响应版本避免较旧快照覆盖新进度，角色版本避免迟到结果覆盖新的角色状态。空checkpoint不会自动采用服务端更晚的进度。

不存在固定Day4广播。剧情引擎通过`PublishStoryEvent(stableId,text,observers,verified,discloseTo)`明确发布，给谁看见和允许给谁转述分开设置。
