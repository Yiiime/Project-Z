# 海风捎来的信 · 核心与叙事开发记录

2026-11-03

## 已实现

- `GameSession.Initialize()` 装配状态、时钟、对话、叙事组件；单独的 `SaveRepository` 负责 JSON 原子替换、备份回退。启动恢复场景位置、日期、剧情选择、物品、日志和未读完对话节点。
- `GameClock` 四个明确时段，休息/咖啡选择推进；夜间可进入次日。天气文字按日期和时段变化，没有依赖真实时间的倒计时。
- `DialogueRunner` 支持多轮、三个以上分支、条件选项、节点完成效果、关闭事件。效果在读完节点/选择时提交，带 flag 的奖励幂等。
- `StoryDirector` 只负责叙事路由、条件事件和目标提示；物理、世界场景加载、UI 独立。
- ScriptableObject：StoryDatabase（对话节点）、3 个 NpcData（独立时段和地点配置）、3 个 ItemData、4 个 StoryEventData。编辑器 `StoryContentBuilder.Build()` 创建持久资产并校验重复节点/断链。
- 三位人物：咖啡店主阿遥、退休邮递员陈伯、摄影学徒澪。街道、咖啡馆、灯塔三个场景对应十余个互动点。
- 故事从捡到旧明信片开始，经由照片和一段旧邮路故事，选择寄给下一位旅人、自己留住、邀请大家拍新照片。三个结尾有独立对话、物品变化与日志记录。
- 手机消息随进度更新；日志不重复添加。关系值有数据接口，当前作为后续扩展记录，不做数值好感度玩法。

## 叙事可恢复性

- 陈伯仅上午/午后出现，但傍晚咖啡馆留言簿能提供完整旧故事和同一选择，手机与目标文本主动指路。
- 澪白天在街道、傍晚/夜晚在灯塔。提前到灯塔可返回补线索；不因时间推进错过结局。
- 在获取线索前访问人物、物件有独立回应；重复交谈不会重复奖励或覆盖选择。
- 所有物件可以先后任意探索。旧明信片为主线入口；咖啡馆再接陈伯或留言簿，完成选择后灯塔会合，再与邮筒交互收尾。
- 三种结局完成后保留自由散步；NewGame 清空当前状态和覆盖本游戏存档。

## 限制与检查边界

- 内容是独立的一日短篇，不代表《来自月亮的 Z》既有长线剧情；名字/设定可替换。
- 预计阅读与探索约 10–20 分钟，尚未由用户实测计时。
- 不含联网 AI 对话、配音、真实短信。手机为剧情内容面板。
- 该记录仅说明实现；Unity 编译、实际走通及视觉验收由整合阶段记录。

## 分支的世界反馈

- 邀请分支到傍晚后，阿遥离开咖啡馆，与陈伯一起在灯塔出现，拥有独立现场短聊。NpcSchedule 通过 requiredFlag / forbiddenFlag 判断剧情条件；其他两条分支维持原日程。

## 最终一致性修订

- 阿遥因邀请分支在傍晚离店后，咖啡物件改用无店主的自助咖啡与纸条叙述。夜晚提供自泡花草茶后休息至次日，取消选项也使用玩家/旁白，不再凭空出现阿遥的现场台词。
- 最终内容为 94 个唯一对话节点。静态复核 55 个 next/choice 引用，全部可解析。
