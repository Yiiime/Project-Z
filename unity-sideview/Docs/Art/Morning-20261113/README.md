## 补图画风与生成边界

仅补充 4 张缺图，使用 `image_gen.imagegen` 以对应现有地图作为几何参考、包内清晨图作为色彩和光照参考。全部采用柔和浅蓝天空、奶油金晨光、冷灰蓝阴影，保留既有建筑、家具、门口、路径和地面位置；不新增角色或 UI。灯塔和玩家房间由原有夕阳/月夜背景改为清晨，森林深处保留林径结构，杂货铺保留货架及出入口。

每张补图的完整 prompt、两张参考图的工程相对路径、工具输出文件名、生成尺寸与 SHA256 已记录在 manifest 的 `generation` 字段。补图为约 1.6K–1.8K 宽的原生输出，没有通过放大旧图冒充新细节。生成式重绘能保留主要结构，不能保证每个小物件逐像素一致。

## 全景画幅与脚线对齐

包内 4 张全景图包含额外天空和下方挡墙，完整画幅与旧地图不同。直接把完整 PNG 压进旧矩形会改变建筑比例和地面高度。`Art/IslandMorning/Layout.json` 为这 4 张图提供脚线；`TimeOfDayMapArtwork` 保持原场景世界宽度，按清晨 PNG 原始宽高比缩放，再让指定脚线对齐原逻辑地面。完整 PNG 保留，超出摄像机画面的部分自然不可见。

其他地图的画幅差异很小，沿用原本地矩形回贴。居民街在首轮 Unity 预览中鞋底落到路缘立面，最终将脚线从 481 修到 470 像素；修后鞋底回到铺路面内，其他三张维持初值。

上述处理只调整背景 SpriteRenderer 的显示变换，不改物理根节点、地面碰撞、场景边界、门口或通路数据。统一脚线只能修正整图对齐，图内局部生成漂移仍需运行时检查。

## 时段选择与原版本保留

`IslandAtmosphere.cs` 内的辅助类由 `EveningMapArtwork` 扩展为 `TimeOfDayMapArtwork`；`IslandAtmosphere` 和旧灯塔的 `SceneAtmosphere` 共用它。`TimePeriod.Morning` 加载清晨目录，`TimePeriod.Evening` 继续加载既有傍晚目录；午后和夜晚恢复原图及对应氛围。切换前始终以原始 Sprite 的中心、矩形和脚线为基准，不会将上一次时段变换累乘。请求的变体缺失时恢复原图。

已有傍晚 PNG 字节、来源映射和全矩形显示方式保持不变。首页动画、BGM 按钮、任务卡和 NPC 转场逻辑不在本次美术变体修改范围内。
