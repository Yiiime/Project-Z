## 美术依据与制作边界

用户提供的夕阳海港参考图用于确定日系手绘背景的色彩与光照：钴蓝天空和海面、蓝紫阴影、橙粉晚霞、暖琥珀灯光。原地图继续决定构图、地平线、建筑、门窗、家具、路线和地面位置，参考图中的船只与建筑不作为新增物件。

制作使用内置 `image_gen.imagegen` 的源图编辑流程。室内保留原有灯具与窗景类型：林间小屋仍是森林窗景；照相馆与酒吧不额外开窗；玩家房间另做傍晚变体，原月夜图不覆盖。杂货铺初版的重复太阳已经弃用，最终采用太阳落到地平线以下的连续晚霞海景。

## 分辨率与后处理说明

独立生成图主要为 **1.6K 级原生输出**，不同画幅的实际宽度约为 1583–2171 像素，逐图精确尺寸见下表与 `manifest.json`。这不是对原图直接放大得到的高清母版。

居民街、公共街和海滨步道采用原图分块、分别生成和接缝拼合，中间画布保留原图坐标以便配准，最终交付统一缩至 **900 像素高**：居民街 4921×900、公共街 3728×900、海滨步道 2939×900。**中间 8300×1518 画布不等于真原生 8K 细节**，不能以拼合画布宽度宣称单次生成清晰度。完整分块及接缝 prompt 记录在 manifest 的 `generationSteps`。

码头图原生生成结果为 2171×724，去除黑边后交付 2171×700。除这项裁黑边和超宽图拼合/缩小之外，其他交付图沿用生成文件，没有放大。下表“导入 PNG”指磁盘上实际交付文件，不冒称 Unity 平台转换后的 GPU 纹理尺寸。

## 傍晚切换与保留范围

`IslandAtmosphere` 为岛上地图加载 `Art/IslandEvening/<PlaceId>`；`SceneAtmosphere` 为保留的旧灯塔场景采用同一资源约定。仅傍晚开启，其他时段恢复原背景和原氛围处理。新图已绘制夕阳色彩，傍晚不再叠加旧的紫色 wash。

`EveningMapArtwork` 将新 Sprite 的完整矩形按原图的本地中心、旋转、宽高分别回贴，从而处理像素尺寸、PPU 与 pivot 差异；该操作不移动物理根节点、不改碰撞和交互入口。原图及变体独立保存，缺少变体时回退原背景。

## 验证范围与待验收项

已完成：32 个启用场景、32 个候选及 32 个运行 PNG 一一覆盖检查；PNG 头部尺寸和 SHA256 读取；生成图的资产级目视核对；Atmosphere 两处集成的只读代码审查。生成式编辑保留主要布局，但细部重建不保证逐像素一致。

本文件不把资产检查或代码静态审查写成 Unity 验收。实际编辑器编译和试玩结果由主任务另行记录，重点包括：

- 傍晚与上午、午后、夜晚切换时的背景恢复及颜色是否重复叠加。
- 门口、台阶、路面、出生点与现有碰撞/交互区域的对齐；整图边框回贴无法修正图内局部几何漂移。
- 超宽图分块接缝在正常摄像机比例下是否出现重复物件、纹理断裂或亮度跳变。
- 室内外往返、场景黑屏转场及 NPC 位置保持。
- 超宽图实际平台导入效果及显存占用。当前 `.meta` 上限为 8192，交付文件最大宽度 4921，没有因超过上限而必须继续缩图；平台格式和压缩效果仍需编辑器查看。
