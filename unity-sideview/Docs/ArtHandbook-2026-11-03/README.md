# 场景美术与地图交付手册

基于用户提供的六张场景设定图，以及当前 `unity_z` 工程。版本 v1，日期2026-11-03。

建议直接打开 `index.html`：离线可读，包含六张参考、风格提炼、当前底图、可切换的地面/交互锚点/镜头框/角色标尺，及三份完整规范。镜头图是按当前参数计算的辅助工具，不是Unity游戏运行画面。

- `01_美术风格指南.md`：共同风格、画法/光色/材质、界面延展与检查标准。
- `02_Unity地图资产规范.md`：五张底图、实际导入参数、三套取景/尺度、碰撞、出生点、全部21个交互锚点、动态与状态限制。
- `03_批量制作单与提示词.md`：可复制制作单、文件包、生成/变体/界面提示词、流程与职责。
- `地图锚点.csv`：现有三地图所有交互点，左上原点像素/归一化坐标与Unity世界坐标；不是物件图形中心。
- `templates/`：交接格式、现有Street真实示例、三张地图的透明SVG标注模板；当前Unity不自动导入这些JSON。
- `evidence/`：保存场景与资源审计、Editor只读结果、源码哈希及文档检查记录。
- `tools/`：重建文档快照/离线HTML的脚本，仅用于本手册。

未改动游戏脚本、原图、场景、导入设置，未运行重建菜单或Play Mode。当前工程不是之前另一目录中的 `z_from_moon` 工程，规格不可交叉套用。

审计期间其他工作更新了角色切片脚本，已记录在 `evidence/Verification.md`；本任务保留该更新，没有把它计作自己的修改或验证成果。
