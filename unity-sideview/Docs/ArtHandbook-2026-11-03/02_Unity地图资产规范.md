## 地面、尺寸与像素坐标：必须一起交付

**现状**：地面碰撞上表面是世界 `y=0`；图片底部 16.5% 留给地台/前缘，即脚底基线距顶部 83.5%。对当前图片，基线为 `y_px=785.735`（通常标到 786），不是图片底边 941。

图片采用左上原点：x 向右、y 向下。Unity 世界 x 向右、y 向上；地图水平中心为 x=0。以下是连续坐标，标注中可保留一位小数，取整仅用于画参考线，不用改变实际配置。

```text
Wpx, Hpx = 图片宽高
W = WorldScene.width
H = W × Hpx / Wpx
f = floorImageFraction = 0.165

图片均匀缩放 scale = W / (Wpx / PPU)
背景中心世界坐标 = (0, H × (0.5-f))
世界坐标 x = (x_px/Wpx - 0.5) × W
世界坐标 y = (1 - y_px/Hpx - f) × H
像素坐标 x_px = (x/W + 0.5) × Wpx
像素坐标 y_px = (1-f-y/H) × Hpx
```

这是当前 `ProjectBuilder` / `SceneAtmosphere` 的装配逻辑；后者切图时会重新计算 scale 与位置，手动改背景 Transform 可能在切时段后被重置。若采用不同 pivot，上述中心定位就不再成立。

**给美术的换图约束**：底图不含人物、UI、提示光点、坐标线、水印、乱码；脚底线水平连续；用现有地图模板叠加核对。装饰地台、海堤立面可以画在基线下，不能把其底边当成行走地面。坡道、台阶、落差与可上平台须另交碰撞标注并由程序改造。

## 昼夜与天气的真实支持边界

`SceneAtmosphere`：Morning/Afternoon 选 `_day`（若存在）；Evening/Night 选主图。Cafe 缺 `_day`，全时段使用 cafe.png。Night 有更深蓝的色层/全局光；Cafe 时段色层被限制在前三档。雾仅在室外且天气文本包含“薄雾”时叠加。

当前 `GameClock` 产生晴/薄雾描述，本次所检装配中未见自动雨景选择或雨粒子。**新增 `_night`、`_rain`、`_morning` 文件不会自动启用。** 将带雨线、窗外城市或人物倒影的整张参考图直接作为通用底图，会使晴天也在下雨、海滨变城景或角色走开后留下倒影。

## 批量交付与验收门槛

美术可以按地点批量产出；程序仍需逐场景装配。首批先完成一张现有地图的替换试点，走通“美术检查→导入→角色行走→镜头左右端→交互→时段→遮挡→目标分辨率”后，把已通过的尺寸和锚点模板锁为批量标准。当前原型中的美术缺口不应被固化为长期风格要求。

**建议验收清单**：

- 图像：尺寸/色彩/alpha正确；没有人物、UI、水印、乱码、残影、重复道具；关键物件明确可见。
- 空间：角色脚底与基线对齐，门/椅/柜台尺度合理；出生点、左右端、跳跃平台与碰撞对应。
- 交互：所有 ID 的视觉语义与实际位置一致；门可达，最近交互不因重叠而长期抢占。
- 取景：Street 左/中/右三个镜头都检查；Cafe/Lighthouse 基本全图检查；不能只看缩略图。
- 状态：切换时段无结构漂移；拾取后物件与阴影一同消失；前后景不重影，不把透明图导成黑底。
