## 开始页

- `StartPageView` 管理菜单、确认框、输入与渐入/退出；`StartPageAtmosphere` 独立绘制低对比海光和远处飞鸟。
- `Resources/UI/StartPage.asset` 引用 #47 的 `Art/Island/Boardwalk.png` 原资源，不复制背景。可配置取景中心、overscan、海光/飞鸟区域、左侧渐变。
- 背景使用保比例裁切与幅度很小的实时取景运动，叠加独立运动层；没有用定时换图冒充动画。没有重新制作角色或引入插件。
- 有有效存档时提供「继续小岛生活」与第几天/时段/地点预览；无有效存档时提供「开启小岛生活」。重新开始有二次确认；主档和备份都损坏时，进入第一天同样需要明确确认。
- 「如何游玩」提供移动、交互、手机、路口说明。声音和动效开关仅作用于本次运行；尚未扩展成持久化全局设置。
- `GameSession.IsAtTitle` 独立控制冻结与禁止保存。`GameBootstrap` 保留场景初始化依赖，推迟 Memory 初始化，直到玩家选择并恢复目标地点。首页停留/取消/退出不会自动建立新进度或覆盖旧档。
- Continue 重新读盘，避免标题预览期状态污染。通过既有 `WorldDirector.Travel` 恢复地点和 X，淡出结束后恢复输入与时间。`-memorySmokeOutput` 保留原直接进入行为。

设计参考：[Chill with You 官方商店页](https://store.steampowered.com/app/3548580/Chill_with_You__LoFi_Story/)的环境陪伴、自然声与克制界面方向；本页使用项目自己的海岛美术和原创排版，不复制其素材或宣称复刻其菜单。

## 演示缺口建议（本轮不实施）

1. **服务就绪与离线保底。** 默认 Memory 模式依赖本机服务、模型配置和同步；核心发送受 `MemoryLabClient.CanGenerate` 限制。直播也依赖外部服务。建议统一就绪提示/重试，并准备明确标注的离线短线，避免演示只剩行走与空聊天框。
2. **约10分钟的首日闭环。** Memory 模式的 `StoryDirector` 跳过旧明信片短篇事件，因此旧 README 的完整短篇不能代表当前八人玩法。建议抵达→认识一人→一件小事→一次行动→一条回忆的推荐路线与结束点。
3. **基础设置持久化。** 暂停音量及本轮首页声音/动效开关仅在运行期有效；建议下一轮统一音量、窗口/全屏、文字大小和减少动效设置，不扩成复杂设置中心。
4. **相册的第一张真实照片。** 当前 PhoneDataService 输出的记忆条目均 `IsPhoto=false`，照片页只有空态。建议先接通一个获得合照的剧情触发，复用已有查看/收藏功能。

这些缺口来自源码审查；真实断线恢复耗时、首日完成率与安装包适配需要后续专门验证。
