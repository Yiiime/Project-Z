# Agent 安装说明：Z 项目协作环境

你是帮助一位没有开发经验的组员安装 Z 项目协作环境的本地 agent。目标：安装工具、下载 `Yiiime/Project-Z`、完成 GitHub 登录，并打开本机协作面板。

## 规则

- 只使用本文件夹里的 `install.sh`；不要从其他来源下载替代安装脚本。
- 所有工具安装在用户目录 `~/.project-z`，项目默认放在 `~/Project-Z`。不要使用 `sudo`，不要修改系统设置。
- GitHub 登录必须由用户本人在浏览器确认。不要要求、读取、打印或保存 token、密码或一次性代码以外的凭据。
- 如果 `~/Project-Z` 已有修改，不要删除、重置或覆盖；先报告给用户。
- 遇到需要用户操作的步骤，用一句中文说明点哪里，然后等待用户完成。

## 步骤

1. 只读检查当前状态：

   ```bash
   bash "<本文件夹>/install.sh" --check
   ```

2. 根据结果处理：

   | 结果 | 下一步 |
   | --- | --- |
   | Git 没有安装 | 运行安装后会弹出 macOS 窗口；请用户点“安装”，完成后再继续 |
   | GitHub 没有登录 | 运行完整安装；它会显示一次性代码并打开浏览器，请用户粘贴代码并授权 |
   | 没有仓库写权限 | 告诉用户把 GitHub 用户名发给 Yiiime，并在 GitHub 通知中接受邀请 |
   | 其他项缺失 | 运行完整安装 |

3. 完整安装，但先不启动面板：

   ```bash
   bash "<本文件夹>/install.sh" --no-open
   ```

   该命令会：下载并校验 Node.js 22、GitHub CLI 和 .NET 8；完成 GitHub 登录和 Git 署名；下载项目；在桌面生成 `打开 Z 协作面板.command`。若下载 .NET 失败，可加 `--skip-dotnet` 重试，GitHub 仍会在合并前检查。

4. 再次运行 `install.sh --check`，确认全部为 ✓。

5. 打开面板：让用户双击桌面上的 `打开 Z 协作面板.command`，或运行：

   ```bash
   open "$HOME/Desktop/打开 Z 协作面板.command"
   ```

6. 告诉用户：
   - 浏览器里的面板地址是 `http://127.0.0.1:4387/`，只在本机有效；
   - 终端窗口要保持打开，关闭会停止面板；
   - 之后在 Codex 里打开 `~/Project-Z` 开发，并先读项目根目录的 `AGENTS.md`。

## 完成后的开发规则

在 `~/Project-Z` 工作时，以项目 `AGENTS.md` 为准。命令行也可以使用安装器生成的 `~/.project-z/bin/z`：

| 命令 | 用途 |
| --- | --- |
| `~/.project-z/bin/z doctor` | 检查环境和权限 |
| `~/.project-z/bin/z start <英文短名> --goal "目标" --area <区域ID>` | 开工并创建草稿 PR |
| `~/.project-z/bin/z save --message "说明" --handoff "交接"` | 保存并推送，PR 保持草稿 |
| `~/.project-z/bin/z ship` | 同步、检查、推送并转为可合并 |

只修改用户所选区域对应的路径；需要超出范围时先询问用户。看到红色重叠提醒时，先让用户和对方确认。

## 失败时

读取 `~/.project-z/logs/` 中最新的安装记录，向用户报告失败的步骤和下一步。不要把记录里的个人信息发到其他地方。
